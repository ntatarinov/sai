# 0034 — REQ-038 строится при незавершённой зависимости REQ-014

Статус: **принято** (ORCH, 2026-10-11, по поручению владельца «Сформируй требования которые ты считаешь полезными для sonnet, после этого я запущу это все твое на sonnet»; владелец может отменить). Образец — `0027`, `0029`.

## Вопрос

REQ-038 (проверка учёта прогонов) использует и расширяет код проверки следов `tools/src/traces/` (REQ-014). REQ-014 остаётся `in_progress`: его открытые пункты — первая перепроверка выполненных требований и проверка на чистой копии в отчёте прогона, а не сам код проверки следов, который работает в `npm run check` с 2026-10-09.

## Решение

REQ-038 получает `depends_on: [REQ-014]` и может начинаться до `done` у REQ-014 — исключение касается только порядка работ, не критериев и не планки. Изменения в `tools/src/traces/` в прогоне REQ-038 проходят те же ворота и не ослабляют тесты REQ-014 (TR-*). REQ-038 не станет `done`, если владелец отменит это исключение, пока REQ-014 не `done`.
