# Решения

Одно решение — один файл `NNNN-<коротко>.md` с разделами «Вопрос», «Варианты»,
«Решение», «Почему», «Граница» (чего решение не касается) и «Основание» (на чьих словах и
каких документах оно стоит); слова владельца — дословно, с датой.

Decisions from 0080 on are written in English and use the English section titles (Question, Options, Decision, Why, Boundary, Basis) for the Russian ones (Вопрос, Варианты, Решение, Почему, Граница, Основание).
