# 0003 — Pixel Office для наблюдения за конвейером — служебный код в `tools/` (Node 22)

Статус: принято (2026-09-30). Подготовил ORCH по прямым поручениям владельца (ниже).
Отдельного вопроса о стеке владельцу не задавалось: выбран тот же стек, который владелец
подтвердил в `0002`. Владелец может отменить это решение одной фразой — тогда REQ-001
снова ждёт `0001`.

## Поручения владельца, дословно

- «не теряй pixel office» (2026-09-25).
- «запусти pixel office и дай ссылку чтобы смотреть на агентов» и «запусти pixel office и
  дай ссылку чтобы я смотрел задачи какие выполняют» (в сессии Claude Code, между
  2026-09-25 и 2026-09-28; точная дата не записана).
- «Ты мощный и сильный разработчик и тебе надо изучить проект и то что не было завершено.
  И теперь стои задача все закончить, справишься?» (2026-09-30).

## Вопрос

REQ-001 (Pixel Office на хуках Claude Code) помечен как блокированный «решением о стеке
продукта (decisions/0001)», а `0001` принимается только после решения владельца о старте
продукта. Можно ли строить Pixel Office, который показывает работу агентов конвейера
Sai, до этого — и на чём?

## Варианты

1. **Ждать `0001`.** Минус: владелец несколько раз просил Pixel Office, а старт продукта
   не назначен; работа агентов остаётся невидимой.
2. **Служебный код в `tools/` по `0002`.** Node 22, без зависимостей во время
   выполнения: сервер на `node:http`, страница — обычный JavaScript и canvas без сборки
   (как клиент эталона `reference/pixel-office-[образец]/wwwroot/`). Одна команда
   проверки — `npm run check` в `tools/` (Q4).
3. **Перенести эталон как есть (.NET 8).** Минус: второй стек и вторая команда проверки
   (Q4) ради служебного инструмента.

## Решение

Вариант 2.

## Почему

Pixel Office здесь — инструмент наблюдения за конвейером: он показывает, что делают
агенты Sai, по событиям хуков Claude Code (R2). Это служебный код того же рода, что
`tools/` для WF-06, и `0002` уже задаёт для него стек и команду проверки. Новых сущностей
на машине не появляется.

## Граница

- Это **не** продукт. Платная версия Pixel Office — линия 1 бизнес-плана
  (`docs/business-plan/README.md`, REQ-006) — продукт; её стек решает `0001` после
  решения владельца о старте. Код, написанный по этому решению, не становится кодом
  продукта без отдельного решения.
- Хуки Claude Code настраиваются только в проекте Sai (`sai/.claude/settings.json`), не в
  пользовательских настройках владельца.
- Сервер слушает только локальный адрес компьютера владельца. Секрет для записи событий —
  вне репозитория (Q7).
- Что именно и как строится — решают требование REQ-001 (REQ-ANALYST → REQ-VALIDATOR) и
  дизайн (CODE-DESIGNER → CODE-DESIGN-VALIDATOR), а не это решение.
