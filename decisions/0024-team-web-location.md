# 0024 — Место сервера и страницы бизнес-интерфейса Sai Team (REQ-011)

Статус: **принято** (ORCH, 2026-10-10, по слову владельца «давай» продолжать по каталогу; владелец может отменить). Уточняет `0015` (граница кода продукта) и `0002` (без зависимостей времени выполнения).

## Вопрос

Решение `0015` разрешало код продукта только в `tools/src/team/`. Требование REQ-011 вводит локальный сервер с `node:http` и страницы. Критерии `REQ-009` (пять мест записи), `REQ-010` (нет сети в исполнителях) и `REQ-013` (нет `node:net`/`node:http` в `tools/src/team/`) запрещают сетевой код внутри `tools/src/team/`.

## Варианты

1. Сервер внутри `tools/src/team/` — ломает три критерия «нет сети в движке».
2. Сервер в `tools/src/web/`, страницы в `tools/src/web/public/`, данные и записи — только через API ядра (импорт из `tools/src/team/`).
3. Отдельный пакет — лишний `package.json`, правило `0002` усложняется.

## Решение

Вариант 2. `tools/src/web/` — единственное место, где разрешены `node:http` и адрес `127.0.0.1` для интерфейса Sai Team (рядом с `tools/src/pixel-office/`, у которого своя папка). Правила:

- сервер слушает только `127.0.0.1`, отвечает только на Host `127.0.0.1:<порт>` или `localhost:<порт>`;
- у сервера нет своего файла состояния и нет записей в файлы мимо API ядра и канала `tools/src/team/engine/channel.js`;
- код `tools/src/team/` сетевых модулей не получает; критерии `REQ-009`, `REQ-010`, `REQ-013` и проверка следов `REQ-014` остаются верными;
- файлы сервера вносятся в список проверки `traces-runtime` (`REQ-014`, критерий 4) в том же прогоне, что и сервер;
- зависимости времени выполнения не добавляются (`0002`); тесты страниц — `jsdom` как devDependency (`0023`, D2).

## Последствия

- `CLAUDE.md` и `README` Sai: граница кода продукта — `tools/src/team/`, `tools/src/web/`, `tools/src/traces/`, `tools/src/pixel-office/`.
- Новое место записи не создаётся: сервер пишет только через ядро и канал.
