# 0071 — Сайт подбора, сервер (REQ-056): выборы проекта кода

Статус: **принято** (ORCH, 2026-10-20, по вопросам О1–О18 проекта `docs/design/REQ-056-picker-server.md`, п. 15.1, прогон `SERVER056-20261020-01`; владелец может отменить). Дополняет `0065`, `0069`, `0070`.

## Решение

Принимаются значения проекта «до ответа» по всем восемнадцати вопросам. Главное:

1. **О1 (приёмка в браузере).** К приёмке REQ-056 страницы анкеты и результата ещё нет (их строят REQ-057 и REQ-058 после него). Приёмка REQ-056: заглушка страницы открывается в браузере на трёх языках, путь «анкета → ответы → результат» проходится запросами `curl` по командам стенда; прохождение анкеты в браузере остаётся приёмке REQ-057 и REQ-058. Критерий 5 REQ-056 (не 4 — поправлено по F1 ворот `step-01c-code-design-validator.json`) в этой части поправляется через WF-01 (REQ-ANALYST и REQ-VALIDATOR, с `before_copy`, прогон `REQAMEND056-20261020-01`) до шага 8 прогона сервера, без ослабления остальных проверок; шаг 9 прогона проверяет уже исправленную формулировку.
2. **О2.** Заглушка страницы со скриптом и ключом `page_stub_notice` — да.
3. **О3.** Результат на сайт отдаётся без `ranking` (баллы и id нерекомендованных решений наружу не уходят; ISS-0077, п. 7). Требование REQ-056 говорит «объект движка» — формулировка уточняется в том же прогоне WF-01.
4. **О4, О5.** Имена полей анкеты и форма тела POST (`{"answers": …}`) — как в проекте; их читают REQ-057…059.
5. **О6.** `Origin` у POST обязателен; `curl` в стенде пишется с `-H "Origin: …"`.
6. **О7–О11.** 308 отбрасывает строку запроса; HEAD и OPTIONS — 405; предел 100 файлов арендаторов; порт по умолчанию 4782; `--home` принимается и ничего не делает до REQ-059.
7. **О12.** Как страница получит правило видимости — решает проект REQ-057; сервер отдаёт только `public/`, `engine.js` не меняется.
8. **О13.** Ошибка программы — код 3; `cli.js` остаётся скриптом, `COMMANDS` не экспортируется.
9. **О14–О18.** `version` — полный sha256; переводы ключей `server_*` и `page_stub_notice` проверяет читатель-агент (спорное kk — знающему казахский человеку, `0069` п. 6); `TENANT_ID` переезжает в `limits.js`, `places.js` получает `tame`; журнал без текста исключения; блоки «не обслуживается» — в stderr.

Дополнение (2026-10-20, по замечаниям F2–F10 ворот проекта, доработка 1 из 3):

10. **F2.** Разбор аргументов `serve`: значение, следом за которым идёт другой ключ (`--port --tenants x`), считается отсутствующим (как у команды `handoff`, `tools/README.md`); порт `startPicker` без значения — по умолчанию 4782; неизвестный ключ `options` — ошибка с кодом 2. Тексты отказов и строки тестов вписывает CODE-DESIGNER.
11. **F3.** Обращение, которое разборщик Node отвергает сам (неизвестное слово вместо метода, мусор, заголовок 20000 знаков), получает закрытый ответ обработчика ошибок разбора: тот же набор заголовков безопасности, тело из таблицы текстов, без текста исключения; тест в SF-6c. Если обработчик нельзя описать без догадок — отступление записывается как О19 и утверждение «неизвестный метод получает понятный ответ» убирается из D17 и п. 5.9.
12. **I3.** Подшаг 56c делится на два: `server.js` и `serve.js` с `cli.js`.

## Почему

Каждый выбор даёт наименьшее изменение выпущенного поведения; О1 честно разводит проверку сервера и проверку страниц, которых нет.

## Граница

Не разрешает публикации в интернете, платных подключений и стройки ИИ. Не меняет `done` у REQ-054, REQ-055, REQ-061.
