# 0007 — Хуки Pixel Office и в сессиях, начатых в соседней папке

Статус: принято (2026-10-01). Подготовил ORCH. Меняет границу `decisions/0003` («хуки только в
`sai/.claude/settings.json`»). Владелец может отменить одной фразой — тогда удаляется файл
`<папка сессий>/.claude/settings.json`.

## Основание

Слова владельца, дословно (2026-10-01): «пиксельный офис сейчас не рабочий, я не вижу анимации
агентов и самих их» и «пиксель офис должен быть рабочий как на скриншоте». Раньше (0003):
«запусти pixel office и дай ссылку чтобы я смотрел задачи какие выполняют».

## Вопрос

Почему офис пустой и как сделать, чтобы владелец видел работу агентов?

## Что выяснилось

- Журнал событий пуст: в `~/.claude/projects/` нет ни одной папки проекта для `sai` — сессия
  Claude Code в `sai` ни разу не запускалась.
- Рабочее пространство VS Code владельца первой папкой называет
  «папка сессий»; сессии Claude Code у владельца, в том числе та, где идёт работа над Sai,
  начинаются там. Хуки из `sai/.claude/settings.json` в таких сессиях не срабатывают.
- Рисование офиса исправно: тестовый сервер во временной папке, настоящий хук и шесть событий
  дали на странице трёх персонажей, задачи «в работе» и журнал (снимок Chrome, 2026-10-01).

## Варианты

1. Владелец запускает Claude Code в папке `sai`. Минус: работа, которую он хочет видеть, идёт в
   сессиях из «папка сессий»; эта работа так и останется невидимой.
2. Те же обработчики в `<папка сессий>/.claude/settings.json` с явным путём к `sai`.
3. Обработчики в пользовательских настройках (`~/.claude/settings.json`). Минус: события всех
   сессий на компьютере, по любым проектам.

## Решение

Вариант 2. Файл `<папка сессий>/.claude/settings.json` — те же семь обработчиков, что в
`sai/.claude/settings.json`, проверенных SECURITY-REVIEWER; единственное отличие — вместо
`${CLAUDE_PROJECT_DIR}` постоянный путь к папке Sai на этом компьютере. Хранится то же, что и
раньше: роль, короткое описание задачи, время; тексты запросов и ответов не хранятся.

## Граница

- Хуки начинают работать только после того, как владелец подтвердит их в Claude Code
  (`/hooks`) или откроет новую сессию: так устроен Claude Code.
- Пользовательские настройки владельца не меняются.
- Это служебный код конвейера по `decisions/0002` и `0003`, не продукт.
