# 0019 — Sai самостоятельный: без ссылок на другие проекты

Статус: принято (ORCH) по слову владельца, 2026-10-06. Владелец может отменить. Снимает «осознанные исключения»
шага 2g `PLAN.md`.

## Вопрос

Sai нужно будет открыть на другом компьютере. Можно ли оставить в нём ссылки на существующие проекты владельца
(названия, папку `reference/` с кодом прежнего проекта, адреса страниц компании-работодателя)?

## Варианты

1. Оставить исключения: историю, `reference/` и два адреса-источника (прежнее решение шага 2g).
2. Убрать всё из файлов Sai: обезличить историю, удалить `reference/`, заменить адреса пометкой.
3. Дополнительно переписать историю git.

## Решение

Вариант 2. Сделано 2026-10-06: (а) история (`handoffs/`, `runs/`, `reports/`) обезличена — названия других проектов
заменены пометками «[образец]», «[система компании]», «[компания]», «[проект владельца]»; хеши копий источников в
`runs/*/run.json` пересчитаны, `original_sha256` оставлен как исторический; (б) папка `reference/` удалена
(`git rm -r`, остаётся в истории git); ссылки на неё в живых документах переписаны на «образец (код прежнего проекта
владельца; в Sai не хранится — использованы снимки `docs/design/samples/`)»; способ проверки критериев REQ-001 и
REQ-007 не ослаблен: они проверяются тестами Sai, не сверкой с кодом образца; (в) два адреса-источника в
`docs/business-plan/research/kpp-vision.md` заменены пометкой «ссылка на страницу компании не хранится в Sai —
источник проверен 2026-09-30», факт оставлен; (г) «Sai Platform» в `docs/product/current-state.md` заменено на «Sai как
продукт».

## Почему

Прямое слово владельца: проект должен быть самостоятельным и открываться на другом компьютере без ссылок на
существующие проекты.

## Граница

Старые коммиты git содержат прежние названия и код `reference/`. Переписывать историю git ORCH не стал: это
необратимо и меняет репозиторий на GitHub; нужно отдельное решение владельца. Общие слова (advisory, legacy и
подобные) в цитатах не являются названиями проектов и не менялись. Решение не меняет код `tools/src`.

## Основание

Слова владельца, дословно (2026-10-06): «я хочу чтобы этот проект был самостоятельным потому что его нужно будет
взять открыть на другом компьютере чтобы не было ссылок на существующие проекты как платформ [образец] legacy
[проект владельца], [проект владельца]».
