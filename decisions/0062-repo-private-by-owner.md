# 0062 — Репозиторий Sai на GitHub закрыт владельцем намеренно

Статус: **принято** (по слову владельца, 2026-10-17; ORCH записал; владелец может отменить). Уточняет `0048`.

## Вопрос

`0048` записало: репозиторий открыт намеренно, защита `main` включена. Чтение GitHub 2026-10-17 (сверка RELEASE-VALIDATOR, `handoffs/DOCSEN-20261017-01/step-09-release-validator.json`) показало: репозиторий закрыт, защиты `main` нет. Кто и когда сменил видимость, в файлах Sai записано не было.

## Решение

Слова владельца 2026-10-17, дословно (`docs/owner-requests/2026-10-17-guide-and-english.md`): «Репозиторий Sai на GitHub сейчас закрытый. Вы закрыли его специально? Мой ответ : да».

- Репозиторий закрыт намеренно. Часть `0048` об открытом репозитории не действует; остальное `0048` (порядок выпуска: отправка в `main` после PASS RELEASE-VALIDATOR; запреты force-push, меток, других веток, приглашений, платных настроек; потолок настоящих запусков) в силе.
- Защита ветки `main` у закрытого репозитория на бесплатном тарифе недоступна (GitHub отвечает 403); её отсутствие — не дефект процесса. Проверка `check.yml` при каждой отправке остаётся.
- ORCH видимость и настройки GitHub не меняет; утверждения о настройках в документах — только после чтения GitHub с датой (AP-102).

## Основание

Слова владельца (выше), `decisions/0048`, `docs/anti-patterns.md` (AP-102), ISS-0057.
