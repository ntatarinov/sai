# 0068 — Сайт подбора: ответы владельца 2026-10-20 (арендаторы, публикация, ИИ, языки) и имя в лицензии

Статус: **принято** (ORCH, 2026-10-20, по словам владельца `docs/owner-requests/2026-10-20-picker-owner-answers.md`; владелец может отменить).

## Решение

1. Арендаторы — клиенты Sai (по слову владельца). Устройство из `0065` (один файл — один арендатор, пути `/t/<id>/`) не меняется; Sai может быть первым арендатором.
2. Публикация: сейчас только локально; публикация для пользователей — после завершения и рабочего продукта, по слову владельца. До этого никаких размещений в интернете без подтверждения владельца (показ временной ссылкой — отдельный шаг с подтверждением в момент создания).
3. Языки: русский (ru), казахский (kk), английский (en). Тексты арендатора и сайта должны быть на трёх языках; формат файла арендатора и ответы движка (REQ-054, REQ-055, уже выпущены) меняются новым требованием WF-01 до REQ-056; сам подсчёт баллов от языка не зависит.
4. ИИ: нужен, но как отдельная необязательная возможность: по умолчанию выключен, подсчёт без ИИ остаётся основой, предел расходов, ключ вне репозитория, персональные данные посетителя в запрос не уходят, платные подключения — только по слову владельца. Подписка Claude Max для сайта не подходит; нужен ключ интерфейса (API) с оплатой по использованию — Claude Haiku или более дешёвый вариант (например, MiniMax); выбор поставщика и бюджет — за владельцем, до ответа стройка ИИ не начинается. Требование — WF-01.
5. Имя правообладателя в `LICENSE`: «N. Tatarinov (GitHub: ntatarinov)» — по единственному автору репозитория (владелец поручил выбор агенту); заменяется одним словом владельца. Дополняет `0064`.

## Почему

Владелец ответил на вопросы ORCH; языки меняют формат данных, который сервер только начнёт читать, поэтому правка дешевле до REQ-056.

## Граница

Не разрешает платных подключений, размещения в интернете и стройки ИИ. Не меняет `done` у REQ-054 и REQ-055: формат расширяется новым требованием, прежние проверки остаются.
