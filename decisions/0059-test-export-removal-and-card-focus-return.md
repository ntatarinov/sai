# 0059 — Pixel Office: удаление экспортов, которые тесты импортируют по имени; возврат фокуса из цепочки карточек

Статус: **принято** (ORCH, 2026-10-15, предложено CODE-DESIGNER, прогон `REQ048-20261015-01`, О5 и О6 проекта `docs/design/REQ-048-049-046-047-interactive.md`; до ворот шага 1b — ворота проверяют и его; владелец может отменить).

## Решение

1. Экспорт модуля страницы, который тесты импортируют по имени, не удаляется на шагах разработки: удаление — отдельным шагом CODE-FIXER после того, как TEST-DESIGNER убрал импорт из тестов, с повтором шагов 3 и 4 (урок прогона `REQ044-20261014-01`, AP прогона: удаление на шаге 2 не давало файлам тестов загрузиться).
2. После перехода из карточки в карточку (агент → запустивший → основная сессия и т. п.) фокус при закрытии возвращается на кнопку, которой открыли первую карточку цепочки; если первую карточку открыли нажатием на холст (кнопки нет) — на кнопку легенды роли первой карточки (уточнено ORCH 2026-10-15, ворота критерия 2 REQ-044).
3. Доска в переговорной: для любой роли вне таблицы `ROLE_NAMES` допускается сжатие строки сильнее 3/4, если название не помещается в три строки (дополняет `0058`, дополнение 2, п. 2); полное название видно в легенде, в «Сейчас», в панели «Задачи» и в заголовке карточки (на холсте подсказки нет; уточнено ORCH 2026-10-15, О10 проекта).

## Почему

Проверка должна видеть все тесты на каждом шаге; пользователь клавиатуры не теряет место, с которого начал; таблица ролей Sai покрывает все роли Sai, а чужие длинные названия не должны ломать доску.
