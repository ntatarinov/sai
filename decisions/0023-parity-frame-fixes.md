# 0023 — Рамка «не хуже [образца]»: поправки после ворот (защита ветки, размер требований)

Статус: **принято** (ORCH, 2026-10-10; владелец может отменить). Поправляет `0022` (D6) и уточняет границы требований REQ-025…REQ-034.

## Вопрос

Проверка требований (handoffs/REQ-20261010-01, шаг 02) нашла девять блокирующих замечаний. Три из них требуют решений, а не только правки слов.

## Решения

- **D1. Защита ветки `main` (меняет 0022 D6).** GitHub отказывает в защите ветки для приватного репозитория без платного тарифа (ответ 403). Поэтому защита ветки **не** требуется как критерий. REQ-030 даёт проверку на GitHub при каждой отправке (workflow Actions: `npm ci`, `npm run check`) и локальную проверку перед отправкой; «обязательность» зелёной проверки обеспечивает процесс (RELEASE-VALIDATOR и ORCH не мержат красное), а не настройка GitHub. Если владелец перейдёт на платный тариф или сделает репозиторий публичным, защита включается отдельной поправкой к этому решению.
- **D2. Размер.** REQ-031 делится на два: REQ-031 — тесты свойств; REQ-033 — тесты страниц на настоящем сервере и настоящем коде страниц через jsdom (devDependency, без браузерного бинарника: ставится `npm ci`, работает на чистой машине REQ-014). Они входят в `npm run check` (правило Q4 «все тесты одной командой»; исключений нет). Снимки настоящего браузера остаются шагом DESIGN-QA-VALIDATOR, а не тестом. Поправка 2026-10-10 после ворот: прежняя редакция D2 выносила браузерные тесты из `check`, это нарушало Q4. REQ-029 делится на два: REQ-029 — выгрузка и загрузка проекта; REQ-034 — версии шаблонов и откат.
- **D3. Места записи.** Критерий 2 REQ-009 про «пять мест записи» относится только к `tools/src/team/`. Новые возможности (здоровье, выгрузка/загрузка, версии шаблонов) живут в своих папках `tools/src/<имя>/`; каждое такое требование перечисляет свои места записи в критерии и проверяет их `grep` по своей папке; запись в журнал и состояние проекта — только через API ядра.
- **D4. Плотность тестов.** Считается так: тестов — число из строки `# tests N` команды `npm test` в `tools/`; строк кода — строки `.js`, `.html`, `.css` и `.mjs` в `tools/src` без тестов. Для [образца] — аналогично: тестов из его команд подсчёта по вида тестов, строк — код сервера и страниц без тестов. Обе команды записаны в критерии REQ-025; сравнение «плотность Sai не ниже плотности [образца]», **без допуска** (слова владельца «одинаковым или лучше»). Сейчас у Sai 43,0 против 43,8: разрыв признан, закрывается новыми тестами при реализации требований; REQ-025 не станет `done`, пока разрыва нет. Поправка 2026-10-10 после ворот: допуск 5 % убран.
- **D5. Зависимости.** REQ-028 зависит от REQ-017 (окно решений); REQ-026 — от REQ-020 (шаблоны).
