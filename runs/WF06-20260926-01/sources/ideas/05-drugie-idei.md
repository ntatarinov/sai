## Малый бизнес Казахстана

| Идея | Что нашли |
|---|---|
| Квизы, которые приводят заявки | Marquiz — лидер, платят за заявки; казахстанский модуль для Битрикса |
| ИИ-бот в WhatsApp | AI LINER, DOS AI (WhatsApp + Kaspi), Green API, edna, студии «под ключ» от 250 000 ₸ |
| Боты для продавцов Kaspi | PriceBot, AlgaTop, SaleScout, iBot, Sinai, FixBot, Kaspibot |
| Ответы на отзывы в 2ГИС и Google | 2ГИС сам продаёт «Отзывы Про» с ИИ-ответами |
| Подбор и ИИ-разбор тендеров госзакупок | Tenderplus, Tenderbot, SmartZakup, TenderCRM |
| Тендеры: ИИ, который сравнивает тендер с конкретной компанией (идея владельца) | Tender Qazpilot уже сопоставляет с профилем, каталогом и сертификатами; Smart Tender — вероятность победы, история заказчика, тарифы 0 / 24 990 / 74 990 ₸ |

## Одежда (идеи владельца)

| Идея | Что нашли |
|---|---|
| AR-примерка через камеру вживую | Нужны 3D-модели каждой вещи и симуляция ткани (уровень Snap). Рынок ушёл в примерку по фото. Google встроил её в поиск, у Wildberries она есть в приложении, Lamoda в Казахстане примеряет обувь |
| Фото одежды на ИИ-моделях для карточек товаров | Botika, MPCard.AI (поддерживает Kaspi), «Фотостудия» Wildberries. Фотосессия 20–50 тыс. ₽ против ~200 ₽ |
| Размер + примерка + заказ в WhatsApp для Instagram-магазинов | Размер — около половины возвратов; подсказка по размеру доказанно снижает возвраты |


| Идея | Что нашли |
|---|---|
| Живой мост / разбор ИИ-сессий (идея владельца) | Картинка занята бесплатно; подсказки для непрограммистов — щель |
| Личный профиль для ИИ, переносимый между сервисами | Память есть у ChatGPT, Claude и Gemini; стартапы MemoryRouter, MemoryLake |
| Голосовой ИИ-администратор на казахском и русском | Роботы уже звонят в поликлиниках Алматы; zvonobot.kz, autocall.kz; казахская речь распознаётся плохо |
| Внутренние программы для малого бизнеса за неделю | Lovable — около $400 млн годовой выручки, 60 % пользователей не программисты |
| Проверяющий агент для кода | CodeRabbit (~140 тыс. платящих), проверка кода от Anthropic, Copilot Reviews |
| Камеры на КПП (идея владельца) | Номера и лица готовы; «что в руках» — щель, но для предприятий |
