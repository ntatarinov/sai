# Vercel и Neon: что сделать вам (часть 1, 15–20 минут)

Это нужно один раз, чтобы у сайта появился публичный адрес. Ничего не публикуется, пока вы сами не скажете «да»
(вопрос про первый адрес я задам отдельно). **Ключи и пароли в чат не присылайте** — вводите их только на сайтах Vercel
и Neon или в своём Терминале.

Что понадобится: аккаунт GitHub, на котором лежит репозиторий sai, и Терминал.

## Шаги

1. Откройте vercel.com → **Sign Up** → тариф **Hobby** (бесплатный) → **Continue with GitHub** и войдите тем же
   аккаунтом GitHub, которому принадлежит репозиторий sai.
2. В Терминале, в любой папке **вне** папки sai, выполните: `npx vercel@64.1.0 login` и пройдите вход в браузере.
   (Версия закреплена; если она будет не найдена — напишите мне, я дам другую.)
3. Создайте проект Vercel **без подключения Git**. В Терминале (опять вне папки sai):
   `npx vercel@64.1.0 project add sai-app` — имя можно другое, но тогда адрес будет `https://<имя>.vercel.app`.
4. На vercel.com откройте проект → **Settings → General**: Node.js Version — **22.x**; Framework Preset — **Other**.
   **Settings → Functions**: регион — **Frankfurt (fra1)**. Git к проекту не подключайте.
5. Подключите базу: vercel.com → ваш проект → вкладка **Storage** → **Create Database** → **Neon** (бесплатный план,
   регион **aws-eu-central-1**, Франкфурт) → привяжите к проекту. Vercel сам добавит переменные `DATABASE_URL` и
   `DATABASE_URL_UNPOOLED`.
6. Введите значения в **Settings → Environment Variables** (окружение Production):
   - `SECRET_PEPPER` — случайная строка. Получить в Терминале: `openssl rand -base64 32 | tr '+/' '-_' | tr -d '='`;
     скопируйте результат прямо в поле Vercel, в чат не вставляйте. Отметьте как **Sensitive**.
   - `APP_ORIGIN` = `https://<имя проекта>.vercel.app`; `PREVIEW_ORIGIN` = `https://<имя проекта>-preview.vercel.app`.
   - `TRUST_PROXY` = `vercel`; `LOG_LEVEL` = `info`; `MIGRATE_ON_BUILD` = `1`.
7. **Deployment Protection** оставьте «Standard».
8. Напишите мне в чат (это не секреты):
   - e-mail аккаунта, которому принадлежит команда Vercel (его адрес должен совпадать с адресом автора коммитов, иначе
     Hobby не примет публикацию);
   - **Project ID** (Settings → General) и **Team ID** (Team Settings → General).

Нигде не запускайте `vercel link` внутри папки sai и не подключайте GitHub-интеграцию Vercel.

## Как понять, что всё готово

- В Терминале `npx vercel@64.1.0 whoami` печатает ваше имя.
- В проекте виден Neon во вкладке Storage, а переменные из шага 6 перечислены в Environment Variables.
- Я получил e-mail и два идентификатора и записал их в журнал работ.

## Если что-то не получилось

Пришлите мне текст ошибки (без ключей). Не пытайтесь «обойти» — я подскажу точную команду.
