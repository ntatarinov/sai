# Проверка «можно ли собирать сайты на подписке Claude» (5 минут)

Нужна, чтобы узнать: умеет ли Claude Code в режиме `--bare` работать на вашей подписке, а не на ключе API. По документации
Anthropic это скорее всего **не сработает** — тогда мы просто перейдём на ключ API, а токен вы удалите (шаги ниже).
Проверка запускается только после вашего «да» на вопрос про настоящие запуски.

**Токен — это секрет.** Не вставляйте его в чат, в файлы папки sai и в письма. Он хранится только в связке ключей
macOS (Keychain).

## Шаги

1. В Терминале (любая папка вне sai) выполните: `claude setup-token`. Пройдите вход в браузере. Терминал покажет длинный
   токен. Если команда `claude` не найдена — скажите мне, и я дам путь к установленному Claude Code.
2. Сохраните токен в Keychain. В Терминале выполните:
   `security add-generic-password -s sai-claude-oauth-token -a sai -w`
   Терминал сам попросит значение — вставьте токен и нажмите Enter (на экране он не отобразится).
3. Очистите окно Терминала (Cmd+K) и закройте то, где токен был виден.
4. Напишите мне в чат «токен сохранён» — без самого токена.

## Если проверка не пройдёт (я скажу об этом сам)

1. Удалите токен из Keychain: `security delete-generic-password -s sai-claude-oauth-token`
2. Отзовите токен в настройках вашего аккаунта Claude (раздел с авторизованными приложениями и токенами).
3. Напишите мне «токен удалён: да» или «нет» — я запишу ответ.

## Что я проверяю этим токеном

Три коротких запуска (сборка в пустой папке, текстовая задача со схемой, текстовая задача без `--bare` с «чистым»
домом), общий потолок 0,30 $ (на подписке — условная стоимость). Результат лежит в `docs/uat/` без секретов.
