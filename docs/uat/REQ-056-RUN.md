## Итог

**Прошло 7 из 8, не прошёл 1 (сценарий 3), не выполненных нет.** Все 18 комбинаций «арендатор × язык × окно» открылись с кодом 200, показали заглушку дословно по `texts.js` на выбранном языке, без горизонтальной прокрутки, без обрезанного текста, с контрастом 21:1 и шрифтом 16 px.

Не прошёл сценарий 3 («в консоли браузера нет ошибок и предупреждений») — ровно по одной причине: свежий браузер сам просит `/favicon.ico`, сервер по правилу «любой неизвестный путь — 404» отвечает 404, и Chrome пишет в консоль строку уровня error «Failed to load resource: the server responded with a status of 404 (Not Found)». Это же происходит во всех 18 комбинациях. Ошибок и исключений скрипта страницы нет, предупреждений нет, запросов не к 127.0.0.1 нет. Важность — Low (находка Ф1): посетитель этого не видит. Нужно решение: чинить (ISSUE-FIXER) или BA-ANALYST признаёт запрос значка вне ожидания «нет ошибок консоли».

Блокирующих провалов нет; провалов по секретам, данным клиентов, внешним адресам и фото (Q7–Q11, R3) нет: запросов к внешним адресам 0 из 72 (18 страниц × 4 запроса), секретов и учётных данных в прогоне не было, фото не использовались.

## Находки

**Ф1. Сценарий 3, все 18 комбинаций — Low.** Ожидалось: в консоли нет ошибок и предупреждений. Получено: в каждой загрузке в свежем браузере одна запись журнала браузера уровня `error` — «Failed to load resource: the server responded with a status of 404 (Not Found)», адрес `http://127.0.0.1:<порт>/favicon.ico` (например, `/t/uchet-pro/` и `/t/svet-marketing/?lang=kk`, окна 1470 × 784, 390 × 844, 320 × 568). Доказательство: запись журнала в разборе каждой комбинации (каталог снимков); `curl -i http://127.0.0.1:<порт>/favicon.ico` — 404, тело 118 байт. Причина (по наблюдению): страница не объявляет значок, браузер просит `/favicon.ico`, список маршрутов закрыт (проект, п. 5.6), и ответ — 404. Предлагается: ISSUE-FIXER выбирает — объявить значок (адрес под `/assets/`, который есть в закрытом списке и под политикой `img-src 'self'`), либо BA-ANALYST записывает, что запрос значка браузером под «нет ошибок консоли» не подпадает. Блокировать выпуск не должно (Low), решение за BA-ANALYST и владельцем.
