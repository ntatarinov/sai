# Release report E2E107-20261116-01 - REQ-107: the team page tested end to end in a real Chrome, with the scripted test executor only

Report date: 2026-11-16 (UTC, from the clock; 2026-11-17 in the owner's local day). Process: WF-02 for REQ-107; the
requirement itself was written and accepted in the WF-01 run `E2E-20261103-01` (`handoffs/E2E-20261103-01/`). The push

**In short.** `npm run check` now also opens the team page (Sai Team) in a real Chrome against a real team server
started in throwaway folders, with the scripted test executor only. The server's Claude program is a trap: a copy of a
small script that writes a marker file if it is ever started; `SAI_TEAM_REAL_RUNS` is never given. So there is no real
run and no spending. The spec creates a project and sees it in the list (also after a reload), runs a project to the end
(«выполнен», «M из M задач», a result), pauses, continues and stops a project (the confirmation, and «Не останавливать»
changes nothing), sends a chat message that is shown as text only and does not send an empty one, shows a failed task
and a data folder that cannot be made in plain words while the server stays alive, and works in the windows 1470×784,
390×844 and 320×568. Chrome of the kit gets one more argument, `--use-mock-keychain` (measured on macOS: without it
Chrome under a fresh home folder does not answer its first navigation). REQ-107 is `done`: all 8 criteria are met,
criteria 1 and 7 with the two named limits below (`decisions/0113` О35). The product code (`tools/src/`) was not
changed.

  fixes (one assertion of the marker after the stop in the two start helpers; `scrollX` equal to 0 in the window check).
