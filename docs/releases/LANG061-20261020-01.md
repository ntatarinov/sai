# Отчёт о выпуске LANG061-20261020-01 — сайт подбора на трёх языках

Дата отчёта: 2026-10-20 (время с часов, UTC). Процесс — WF-02, шаг 13, требование REQ-061. Отправка в `main` — по
`decisions/0048` после PASS RELEASE-VALIDATOR (`handoffs/LANG061-20261020-01/step-11-release-validator.json`); учёт сверен ORCH после
шага 12 (`step-12-doc-updater.json`). Вместе с выпуском уходит ещё один коммит — прогон WF-01 `PICKERLANG-20261020-01` (ответы
владельца 2026-10-20, требования REQ-061…063, решения 0068 и 0069), он был сделан раньше и лежал только на этом компьютере.

**Коротко и прямо.** Файл арендатора (компании, для которой сайт подбирает решение) теперь пишется на трёх языках: русском,
казахском и английском. Два вымышленных арендатора («Учёт-Про» и «Свет Маркетинг») переведены. Язык выбирается адресом `?lang=`,
по умолчанию — русский. Язык меняет только слова: баллы, порядок решений и «явный лидер» от языка не зависят. Старый
одноязычный формат по-прежнему читается как «только русский». Но сайта пока нет: ни страниц, ни сервера. Посмотреть результат в
браузере нельзя.

## Что готово

- **Формат файла арендатора `sai-picker-tenant/2`.** Каждый текст для посетителя — набор из трёх строк (русская, казахская,
  английская). Прежний формат `/1` команда проверки принимает как раньше; любое другое значение отвергает понятной строкой.
- **Проверка перевода.** Нет перевода, лишний язык, строка вместо набора — ошибка с точным местом, вплоть до языка. Правила
  понятности (длина текста, не больше 18 слов во фразе) действуют на каждом языке; запрет обращения «ты» — только в русском.
- **Выбор языка и таблица текстов сайта.** Правило «адрес `?lang=`, затем сохранённый выбор, затем русский» и файл
  `tools/src/picker/public/texts.js` с названиями языков и надписями сайта. Файл не обращается ни к сети, ни к Node: его можно
  отдавать в браузер.
- **Два вымышленных арендатора на трёх языках** — по 297 текстов на язык (152 и 145). Копии прежних файлов `/1` сохранены байт в
  байт для проверки старого формата.
- Решение `0070` (договорённости о языках), проект `docs/design/REQ-061-picker-languages.md`, дефект ISS-0080 заведён, ISS-0078
  и ISS-0079 дополнены, уроки AP-113 и AP-114.

## Как проверяли

- Все 10 критериев REQ-061 перепроверил RELEASE-VALIDATOR своими запусками: девять выполнены полностью, критерий 8 (перевод читают
  читатели) — только в той части, которую может проверить агент (см. ниже).
- Тестов стало **1780** (было 1720); `npm run check` — код 0, ничего не пропущено; следов — 0. В этом шаге проверка запущена ещё
  раз: код 0, 1780 из 1780.
- Намеренные поломки кода («мутанты»): на итоговых тестах пойманы **113 из 113**. RELEASE-VALIDATOR нанёс ещё 18 собственных
  поломок — все пойманы.
- Независимая сверка: RELEASE-VALIDATOR своим генератором составил 2000 наборов ответов (по 1000 на каждого арендатора). Результат
  подбора (видимые вопросы, баллы, порядок, исход) одинаков на русском, казахском и английском; расхождений 0. Кривые файлы (500
  вариантов испорченного файла арендатора, пустой, огромный, не в UTF-8, глубоко вложенный) команду не роняют.
- Переводы читали отдельные агенты-читатели в трёх кругах. Казахский: «нет» у 21 пары в первом круге, у 5 во втором, у 0 в
  третьем; английский: у 12, 2 и 0. Итоговое «да» — у **297 из 297** фраз на каждом языке; тексты в файлах равны тому, что читатель
  видел в последнем круге.
- Ворота прогона: проект — PASS; безопасность — PASS (дважды); ревью — сначала FAIL (две записи по-разному читали число «0,125»,
  код годен), после правки записей PASS; тесты — сначала FAIL (тесты ловили 134 из 140 поломок проверяющего, три выживших были
  настоящими), после доработки PASS.

## Что не доказано и что не сделано

- Страниц, сервера, приёма заявок и публикации в интернет нет. Выбор языка и таблица текстов проверены тестами и пробами, но не в
  браузере.
- **Казахский перевод делал агент, а читали его тоже агенты, не носители языка.** Они расходились между кругами. Итоговое «да»
  297 из 297 — это «агенты-читатели не нашли ошибок», а не «казахский безупречен». Пять строк нужно показать знающему человеку до
  публикации: kk 105, 121, 139, 141, 160. В строке 139 вместо «бюджет» стоит «қаражат» (в остальных девяти текстах «бюджет»), в
  строке 141 добавлено «сауда» (торговые), строка 160 в первом круге была по смыслу обратной и исправлена.
- Английский читал тоже агент; строк, требующих носителя, для него не названо.
- Сообщения команд и инструкция арендатору остаются только на русском (решение `0069`, п. 5).
- Два нестабильных теста, EN-62 и HC-6a (ISS-0075), иногда краснеют без причины в коде. В этом прогоне они не падали.
- Файл `/2` с опечаткой в значении `schema` печатает до 100 строк ошибок «Ожидается строка» (первая строка — про `schema`); для
  оператора это шум (решение `0070`).
