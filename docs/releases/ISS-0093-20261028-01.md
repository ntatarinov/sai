# Release report ISS-0093-20261028-01 - result files of the team stored byte-exact (REQ-102, defect ISS-0093)

Report date: 2026-10-30 (UTC, from the clock). Process: WF-03 (defect), with requirement REQ-102 written inside the run.
The push to `main` is made under `decisions/0048`, `0062`, `0079` item 1, after the PASS of RELEASE-VALIDATOR
(`handoffs/ISS-0093-20261028-01/step-10-release-validator.json`, completed 2026-10-30T04:10:51Z) and after ORCH's check of the
bookkeeping (`context.orch_check` of `step-11-doc-updater.json`, 2026-10-30T13:46:32Z). The owner gave the word for the release in the chat on
2026-10-30. The report is in English by `decisions/0080`, item 2.

**In short.** A file that the team engine stores as a result is now stored byte for byte. Before, the free-text masking of
secrets rewrote code files (a version like `0.1.0` or a chain like `a.b.c` became `[скрыто]`), so a stored result was a broken
copy of the source. Now the file is kept exactly, and a file that really holds a secret is refused as a whole, with a short
text, and nothing of it reaches the disk or the journal. Defect ISS-0093 is closed, REQ-102 is `done`. The release also
carries the records of earlier closed M0 runs that were never released (see "What went into the release").
