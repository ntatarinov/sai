# Release report PAGE057-20261021-01 - REQ-057: the card and the questionnaire page of the picker site

Report date: 2026-10-25 (UTC, from the clock). Process: WF-02, requirement REQ-057 (part 4 of the picker site).
The push to `main` is made under `decisions/0048` and `decisions/0057` after the PASS of RELEASE-VALIDATOR
(`handoffs/PAGE057-20261021-01/step-28-release-validator.json`). Bookkeeping is by DOC-UPDATER
(`step-29-doc-updater.json`); ORCH's check is in its `context.orch_check`. The report is in English by `decisions/0080`, item 2.

**In short.** The first page of the picker site that a visitor can use is built: the tenant's card (name, intro, number of
questions, "Take the survey" / "Continue" / "Start over") and the questionnaire itself, one question per screen, in three
languages, with honest progress, saved answers, a language switch without reload, and clear messages when there is no
connection. The 11 tests of this page that were red in all earlier releases are green, and `npm run check` is green:
1998 tests, 1998 pass, 0 skipped, 0 todo (it was 1898 tests with 11 red).
