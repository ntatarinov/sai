**In short.** `npm run check` now also opens the solution picker site in a real Chrome, the way a visitor does: in
Russian, Kazakh and English, in the light and the dark theme, in the windows 1470×784, 390×844 and 320×568; it goes
through the questionnaire to the result, checks the answers against the server, keeps two tenants apart, opens a bad
address, and stops the server in the middle to see the page keep the answers and say so. REQ-105 is `done`: all 10
criteria are met (criteria 1, 4, 6 and 8 with the readings of `decisions/0109`, below). The code of the site was not
changed. REQ-106 and REQ-107 are not built.

## What was done

- **The picker spec** `tools/test/e2e/picker.e2e.js`: nine real-Chrome tests, one per criterion 1-9 - `matrix` (the card
  and the first question in 18 combinations of language, theme and window, counted), `pass` (full passes with the answer
  sets `leader`, `close`, `none`; the answer the page got is equal to a direct request to the server), `themes` (contrast
  of at least 4.5 in both themes by the WCAG formula), `keyboard` (Tab, Shift+Tab, Enter and Space only, one reload, a
  visible focus ring, the live region), `storage` (one key per tenant, the five fields, restart removes it), `isolation`
  (two pairs of tenants: no text of tenant A on the screens, in the answers or in the storage of tenant B), `not found`
  (five bad addresses give the same 404 page), `no connection` (the server stops; the page shows «Нет связи. Ваши ответы
  сохранены. Попробуйте ещё раз.» and keeps the stored answers byte for byte), `v3` (the tenants `agency` and `stock`).
  Criterion 10 is the command `cd tools && npm run e2e -- picker` with its time limit and the independence of the tests.
- **The server starter** `tools/test/e2e/kit/stand.js` (`startStand`, `withStand`, exported by
  `tools/test/e2e/kit/index.js`): starts a server process with a short named list of environment variables (never the
  whole environment), in its own process group registered for the clean-up of the kit, reads the link from its output
  (a local address only), stops it with SIGTERM and requires exit code 0 (`decisions/0109` О8, О13, О14).
- **The starter's own tests** `tools/test/e2e-stand.test.js`: 20 tests with a stand-in server
  (`tools/test/fixtures/e2e-stand/fake-stand.js`) and a fixture spec (`tools/test/fixtures/e2e-stand/specs/sleep-stand.e2e.js`).
- **Three released guard tests** of `tools/test/e2e-kit.test.js` (E2K-50, E2K-41, E2K-60) were edited by the replacement
  table of the design (`decisions/0109` О9); none was removed or weakened (Q6); the file still has 52 tests.
- **`tools/README.md`**: the row of `picker.e2e.js`, the budget words and the paragraph "Servers for the page specs".
- **Not changed:** `tools/src/` (the picker server, the page and the tenant files), `tools/package.json`,
  `tools/test/e2e/run.js`, `.github/workflows/check.yml`. No dependency was added.
- **Documents:** `decisions/0109` (conventions of the starter and the spec, answers О1-О23), `decisions/0110` (the check
