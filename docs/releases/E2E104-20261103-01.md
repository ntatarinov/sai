# Release report E2E104-20261103-01 - REQ-104: the real-Chrome end-to-end kit in `npm run check`

Report date: 2026-11-03 (UTC, from the clock). Process: WF-02 for REQ-104; the requirement itself was written and
accepted in the WF-01 run `E2E-20261103-01` (`handoffs/E2E-20261103-01/`). The push to `main` is an ordinary push under
`decisions/0048`, `0062`, `0079` item 1, after the PASS of RELEASE-VALIDATOR
(`handoffs/E2E104-20261103-01/step-09-release-validator.json`). Bookkeeping is by DOC-UPDATER
(`step-10-doc-updater.json`). The report is in English by `decisions/0080`, item 2.

**In short.** `npm run check` now has a sixth and last step, `npm run e2e`, that starts a real Chrome, opens a local page
and checks it. The kit that does this is small, pure Node 22 and has no new package. A missing Chrome FAILS the check with
one clear line; it is never skipped. REQ-104 is `done`: all 13 criteria are met. REQ-105...REQ-107 are not built.

## What was done

- **The kit** `tools/test/e2e/kit/` (`browser.js`, `cdp.js`, `cleanup.js`, `console.js`, `errors.js`, `find-chrome.js`,
  `guards.js`, `index.js`, `page.js`, `runner.js`): finds Chrome (`SAI_CHROME` first, then the usual places), starts it with
  a private profile folder, talks to it through the debugging port on 127.0.0.1 only, never turns the sandbox off, cleans
  its processes and folders on every exit path, prints a clear one-line error with no stack.
- **The command** `npm run e2e` (`tools/test/e2e/run.js`) with the choice of a spec by name (`npm run e2e -- smoke`), the
  `e2e: browser=`, `e2e: file=` and `e2e: command=... selection=... exit=... duration_ms=...` lines.
- **The smoke spec** `tools/test/e2e/smoke.e2e.js`: 13 real-Chrome tests (start, sizes, overflow, light and dark theme,
  console entries, favicon, local address only).
- **The kit's own tests** `tools/test/e2e-kit.test.js`: 50 tests with a fake Chrome (`tools/test/fixtures/e2e/`: the fake,
  10 spec fixtures, 5 TAP texts), including fault tests that check the state after (no folders, no processes left).
- **`tools/package.json`**: `scripts.e2e` is new and `scripts.check` is six exact steps joined by `&&`. No dependency was
  added; the lock file is unchanged.
- **Five existing guard tests** (`handoffs-cmd-docs`, `handoffs-docs`, `picker-config`, `picker-look-property`,
  `team-web-control`) were re-pointed at the new end of the check by the replacement table of the design; none was deleted or
  weakened (Q6).
- **Documents:** `decisions/0107` (Chrome is needed and the e2e tests belong to the check; accepted, on the owner's answers
  of the same day), `decisions/0108` (kit conventions), `docs/design/REQ-104-e2e-chrome-kit.md` (with the section
  "As built"), `tools/README.md` and `README.md` (Chrome, `SAI_CHROME`, the six steps), `docs/requirements.yaml` (REQ-104
  `done` with an honest note; two outdated words about the end of the check corrected in REQ-038 and REQ-040), `STATE.md`,
  `PLAN.md`, `decisions/README.md`, `docs/anti-patterns.md` (AP-140...AP-143).
- **Defects opened (Low, left open):** ISS-0100, ISS-0101, ISS-0102.
