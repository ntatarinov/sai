# Отчёт о выпуске PICKER055-20261019-01 — сайт подбора, часть 2: движок подбора

Дата отчёта: 2026-10-19 (время с часов, UTC). Процесс — WF-02, шаг 11, требование REQ-055. Отправка в `main` — по
`decisions/0048` после PASS RELEASE-VALIDATOR (`handoffs/PICKER055-20261019-01/step-09-release-validator.json`); учёт сверен ORCH после
шага 10 (`step-10-doc-updater.json`).

**Коротко и прямо.** Готов движок подбора — модуль `tools/src/picker/engine.js`. Ему дают файл одного арендатора (компании, для которой
сайт подбирает решение; файл уже проверяет команда из прошлого выпуска) и ответы посетителя. Он отвечает: какие вопросы теперь видны,
сколько баллов у каждого решения, какие решения лучшие, есть ли среди них «явный лидер» или «близкие варианты», какие гипотезы о проблеме
верны и почему получен каждый балл (какое правило и какой ответ). Кривые ответы он не пропускает, а возвращает понятную ошибку с
номером вопроса и причиной. Но сайта пока нет: ни страниц, ни сервера. Посмотреть движок в браузере нельзя.

## Что готово

- **Движок** — чистая функция: без файлов, сети, часов, случайности и ИИ. Одинаковые ответы дают побайтно одинаковый результат, входные
  данные он не меняет. Все слова в результате берутся из файла арендатора.
- **Проверен на двух вымышленных арендаторах** («Учёт-Про» и «Свет Маркетинг»): на шести наборах ответов исходы совпали с расчётом,
  сделанным заранее вручную (явный лидер, близкие варианты, ничего не подошло).
- **Решение 0067** (число посетителя в объяснении, скрытые ответы игнорируются, в результате есть полный порядок решений, ошибка
  ответов одна — первая); проект `docs/design/REQ-055-picker-engine.md`; дефект ISS-0079 (мелочи тестов, LOW); дополнены ISS-0075 и
  ISS-0077; уроки AP-110 и AP-111.

## Что не доказано и что не сделано

- Страниц, сервера, приёма заявок и публикации в интернет нет. Движок проверен только на двух вымышленных арендаторах и на небольшом
  файле из тестов; утверждение «ни одно правило не пропущено» проверено на 1000 наборах для каждого из двух арендаторов.
- В результате движка есть полный порядок решений с баллами и строка из ответа посетителя в ошибке. Что из этого увидит посетитель,
  решит сервер (REQ-056); это записано в ISS-0077 (пункты 6–8).
- Два нестабильных теста, EN-62 и HC-6a (ISS-0075), иногда краснеют без причины в коде. EN-62 упал один раз в проверке тестов этого
  прогона; на копии без изменений работы он зелёный, в остальных запусках тоже.
