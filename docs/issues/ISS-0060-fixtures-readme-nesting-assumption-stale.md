# ISS-0060 — Строка «вложенность — допущение до записанного настоящего запуска» в README образцов `stream-json` устарела

Серьёзность: LOW. Статус: open. Найдено: RELEASE-VALIDATOR (прогон `REAL-20261013-01`, шаг 9, F2), заведено DOC-UPDATER, 2026-10-13. Пункты планки: Q3, Q14. Требования: REQ-010 (критерий 6, критерий 14).

## Что не так

`tools/test/fixtures/team/README.md` в разделе «Источник образцов `stream-json`» (абзац и столбец «Источник» таблицы) говорит: форма образцов — по `claude --help` 2.1.289 и именам полей, «вложенность — допущение до записанного настоящего запуска (критерий 14 REQ-010)». С тех пор состоялись две настоящие сессии Claude Code (11 и 13 октября 2026; в последней 14 запусков), разбор потока прошёл все без расхождений: расход и активность получены. Строка говорит «допущение», хотя форма подтверждена косвенно.

Честная формулировка: форма подтверждена косвенно двумя настоящими сессиями, побайтно не сверялась — сырой поток не сохранялся (`docs/uat/REAL-RUN-20261013.md`, раздел «Что не проверялось»). Побайтная сверка остаётся за следующим настоящим запуском с сохранением сырого потока вне проекта.

## Доказательство

`handoffs/REAL-20261013-01/step-09-release-validator.json` (`result.findings`, F2); `docs/uat/REAL-RUN-20261013.md`; `grep -n 'допущение' tools/test/fixtures/team/README.md`.

## Как исправить

Отдельная работа по WF-03 — **не** в прогоне учёта: файл читает тест `EX-21` (`tools/test/exec-stream.test.js`), поэтому правка требует всей проверки `npm run check`. Тест не закрепляет слово «допущение», но требует, чтобы в строке каждого образца в таблице стояло «форма по `claude --help` 2.1.289» или «то же», и чтобы в README были слова «Источник образцов» и «2.1.289»; правка должна их сохранить. Обновить абзац и столбец «Источник»: «форма подтверждена косвенно настоящими сессиями 2026-10-11 и 2026-10-13, побайтно не сверялась». Если правка потребует изменить слова, которых ждёт тест, — поправить тест вместе с текстом, в одной работе (урок AP-077, AP-079).
