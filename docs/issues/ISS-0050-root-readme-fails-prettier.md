# ISS-0050 — Корневой README.md не проходит prettier, и `npm run check` его не проверяет

Серьёзность: LOW. Статус: open. Найдено: REVIEWER (прогон REQ030-20261012-01, `step-04-reviewer.json`, I2), 2026-10-13. Пункты планки: Q4, Q6. Требования: REQ-030 (критерий 5 ссылается на README).

## Что не так

Корневой `README.md` не проходит `prettier --check` уже в версии из HEAD: не хватает пустых строк у списков около строк 95 и 106. Команда `cd tools && npm run check` корневые файлы не форматирует — `prettier .` запускается только внутри `tools/`, — поэтому красного не видно. Работа REQ-030 к причине отношения не имеет и ошибку не добавила.

## Доказательство

`handoffs/REQ030-20261012-01/step-04-reviewer.json` (I2). Воспроизведение: из корня Sai запустить prettier с проверкой на `README.md` версии из HEAD.

## Как исправить

Решить, нужна ли проверка форматирования корневых документов (расширить `format:check`) или корневые файлы остаются вне проверки; в первом случае сначала привести `README.md` к виду prettier. Правка команды проверки — отдельным требованием, не в рамках REQ-030.
