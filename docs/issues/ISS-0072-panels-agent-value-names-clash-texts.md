# ISS-0072 — Pixel Office: внутренние константы значений фильтра «Агент» в `panels.js` названы так же, как тексты `texts.js` с другим смыслом (`AGENT_MAIN`, `AGENT_ORCH`)

Серьёзность: LOW. Статус: open. Найдено: REVIEWER (прогон `REQ048-20261015-01`, шаг 4, повтор r1, N1); заведено DOC-UPDATER (шаг 10), 2026-10-16. Пункт планки: Q12 (ясность кода; ошибки сейчас нет). Требования: REQ-046 (критерий 1, фильтр «Агент»).

## Что не так

В `tools/src/pixel-office/public/panels.js` (строки 381–382) объявлены внутренние константы значений фильтра «Агент»: `const AGENT_MAIN = "main"` и `const AGENT_ORCH = "orch"`. В `tools/src/pixel-office/public/texts.js` (строки 297–298) есть экспорты с теми же именами и другим смыслом — это строки экрана поля «Агент» раскрытия события: `AGENT_MAIN = "основная сессия: у этого события агента нет"`, `AGENT_ORCH = "оркестратор"`; их импортирует `event-details.js` (строки 11–12).

Ошибки сейчас нет: `panels.js` эти тексты из `texts.js` не импортирует, а значения фильтра проверяет тест JN-01. Но одинаковые имена с разным смыслом в соседних модулях легко перепутать при следующей правке: импорт `AGENT_MAIN` из `texts.js` в `panels.js` (или наоборот) молча подменит значение фильтра строкой экрана.

## Доказательство

`handoffs/REQ048-20261015-01/step-04-reviewer-r1.json` (findings, N1, Low, не блокирует). Проверить: `grep -n "AGENT_MAIN\|AGENT_ORCH" tools/src/pixel-office/public/*.js` — объявления в `panels.js` 381–382, экспорты в `texts.js` 297–298, импорт в `event-details.js` 11–12.

## Как исправить

Предложение REVIEWER: переименовать внутренние константы `panels.js` (например, `AGENT_VALUE_MAIN`, `AGENT_VALUE_ORCH`) при следующей правке этого файла; значения (`main`, `orch`, `role:<роль>` — проект `docs/design/REQ-048-049-046-047-interactive.md`, D11) и тексты экрана не меняются. Отдельной работы не требует — можно вместе с ближайшей правкой фильтров журнала.

CODE-FIXER (переименование) → SECURITY-REVIEWER → REVIEWER → TEST-RUNNER (JN-01 проходит без правки) → RELEASE-VALIDATOR → DOC-UPDATER → RELEASE-FINALIZER; по WF-03 или вместе с ближайшей работой над `panels.js` — решает ORCH.
