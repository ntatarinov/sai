# ISS-0023 — Проверяющий на настоящем Claude не видит файл результата задачи

Серьёзность: HIGH. Статус: open. Найдено: первый запуск движка на настоящем Claude Code (ORCH, 2026-10-11, проект во временной папке вне проекта, потолок 1). Пункт планки: Q1 (критерий требования выполняется на настоящей системе), Q10. Требования: REQ-013 (критерий 13), REQ-010 (критерий 14).

## Что произошло

Цель: «Подготовь одну страницу: три коротких совета владельцу кофейни, как получить первых 10 постоянных клиентов». Движок на `claude-cli`:

1. Менеджер проекта составил план из 4 задач (исследователь, маркетолог, проверяющий, дизайнер) — запуск r-00001, 0,075.
2. Исследователь написал `memo_research.md` (4102 байта), файл принят ядром как `t-0001-1-memo_research.md` (событие RESULT_FILE) — r-00002.
3. Проверка задачи (роль reviewer, r-00003) ответила: «файл memo_research.md отсутствует в текущей рабочей папке» — REVIEW_RESULT passed: false.
4. Задача переделана (r-00004, тот же файл заново), проверка снова не нашла файл (r-00005) — и так до исчерпания попыток; проект встал в «ждёт решения пользователя» на задаче t-0001, расход 0,67 из 1. Проект остановлен ORCH (событие PROJECT_STOPPED).

Отдельный запуск одной задачи (`run-task`, без проверки) прошёл: файл `t-0001-1-note.md` принят, расход 0,047 — критерий 14 REQ-010 по сути выполнен.

## Причина (предположение, проверить диагнозом)

После приёма ядро удаляет исходник файла из `work/` (README, «Файлы результата»: «Исходник принятого файла в `work/` после приёма удаляется»), а проверяющий запускается в рабочей папке, где файла уже нет; принятый файл лежит в результатах проекта под новым именем. В тестах это не видно: исполнитель scripted не читает файлы.

## Как исправить

WF-03 с шага 1 (ISSUE-FIXER): запуску проверки передавать принятые файлы задачи (копию или путь к результатам, только чтение) и их имена в задании; регрессионный тест на исполнителе, который действительно читает файл; повторить запуск на настоящем Claude с потолком.

Журнал проекта `p-20261011-75cae7` во временной папке сессии (события 1–50: PLAN_RECEIVED, RESULT_FILE, REVIEW_RESULT passed:false ×N, PROJECT_WAITING, PROJECT_STOPPED).
