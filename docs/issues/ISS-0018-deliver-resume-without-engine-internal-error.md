# ISS-0018 — `deliver` для команды resume без движка бросает E_INTERNAL

Серьёзность: LOW. Статус: open. Найдено: CODE-DESIGNER прогона `PROD-20261011-01` (`handoffs/PROD-20261011-01/step-01-code-designer.json`, I2). Пункт планки: Q10.

## Что не так

В описании требования REQ-035 сказано, что `deliver` для `resume` без работающего движка «только пишет событие». На деле он бросает `E_INTERNAL` и ничего не пишет: `tools/src/team/engine/channel.js` передаёт `config: null`. На сервер это не влияет (по проекту REQ-035 сервер сам запускает движок в режиме resume, `0030` п. 2), но поведение канала расходится с описанием.

## Как исправить

Решение CODE-DESIGNER (WF-03): либо `deliver` отдаёт честный отказ «движок не запущен» с кодом ядра, либо описание канала в проекте REQ-013 приводится к факту; тест на оба исхода.
