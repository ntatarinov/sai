# ISS-0049 — Документы Sai называют репозиторий приватным, а он публичный

Серьёзность: LOW. Статус: open. Найдено: CODE-DESIGN-VALIDATOR (прогон REQ030-20261012-01, `-r1`), 2026-10-12; подтверждено SECURITY-REVIEWER (F2), 2026-10-12. Пункты планки: Q3, Q12, Q14. Требования: REQ-030.

## Что не так

Репозиторий Sai на GitHub публичный: на 2026-10-12 запрос к API репозитория даёт `private: false`, `visibility: public`, запрос без токена — HTTP 200, запрос защиты `main` — 404 «Branch not protected» (для приватного репозитория без платного тарифа ответ был бы 403). По `PLAN.md` он стал публичным 2026-10-12 между 00:40 и 04:15 UTC (последнее обновление репозитория — 04:15:33Z); видимость менял не ORCH, и её намеренность не подтверждена. Документы Sai при этом называют его приватным:

- `decisions/0023-parity-frame-fixes.md`, D1 — отказ от защиты ветки основан на «приватном репозитории, ответ 403»;
- `docs/requirements.yaml` — описание REQ-030;
- `README.md` — строка около 182 («репозиторий есть (приватный, на GitHub)»);
- `STATE.md` — раздел о границах («свой репозиторий есть (приватный…)»);
- `PLAN.md` — шаг 2f и связанные строки;
- `.claude/agents/release-finalizer.md` — описание и раздел «Честно о сегодняшнем дне».

Из-за этого основание D1 решения 0023 не совпадает с фактом: защита ветки в публичном репозитории доступна.

## Доказательство

`handoffs/REQ030-20261012-01/step-01b-code-design-validator-r1.json` (F1), `step-03-security-reviewer.json` (F2), `step-04-reviewer.json` (L2, I3); поиск `grep -n 'приватн'` по перечисленным файлам.

## Как исправить

Только после ответа владельца, намеренно ли репозиторий публичный. Если намеренно: поправка к `decisions/0023` (D1) — включить защиту `main` с обязательной проверкой `check` или подтвердить, что остаётся процесс (решает владелец, R1); слово «приватный» исправить в перечисленных документах (в README после П-2 вместе со строкой «CI нет»). Если нет — вернуть видимость решает владелец. До ответа исправлять документы нельзя: правда о видимости зависит от его слова.

## Маршрут

Вопрос владельцу через ORCH; затем WF-03 с шага 1 (документы) и, при решении о защите ветки, запись в `decisions/`.
