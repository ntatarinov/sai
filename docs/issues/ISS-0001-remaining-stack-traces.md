# ISS-0001 — Оставшиеся трассировки стека на нереалистичных путях

Серьёзность: LOW. Статус: closed, 2026-09-30. Найдено: RELEASE-VALIDATOR, 2026-09-28
(финальная проверка REQ-002…004). Пункт планки: Q10.

## Что не так

Вместо кода ошибки и понятного сообщения выводится трассировка стека Node, если:

1. `verdict-N.md` — папка или файл без прав на чтение (`tools/src/validate.js`, чтение
   `.md` в `checkVerdict`);
2. `STATE.md` — папка (`tools/src/apply.js`, чтение STATE.md);
3. `snapshot-diff` получает папку вместо файла снимка (`tools/src/cli.js`, `read`).

## Почему LOW

Все три случая — не реалистичные сбои (такие пути создаются только намеренно), ни один
не приводит к записи неверных данных: команда падает до записи.

## Как исправить

Читать через `readTextFile` (`tools/src/util.js`) и выдавать `E_VERDICT_MD`,
`E_STATE_ANCHOR` и `E_USAGE` соответственно; тест на каждый случай. Исправление делает
BACKEND-DEV (см. AP-009), проверяет REVIEWER.
