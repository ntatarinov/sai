# ISS-0076 — Pixel Office: дефект понятности гайда и карточек после прогона REQ-050…REQ-053 — фразы, которые читатели и приёмка отметили как непонятные (первой — UNKNOWN_ERRORS в карточке)

Серьёзность: MEDIUM. Статус: open. Найдено: читатели без контекста второго круга, UAT-RUNNER и BA-ANALYST (прогон `REQ050-20261017-01`, шаг 8; список — подпись `step-08c-ba-analyst.json`, I9); заведено DOC-UPDATER (шаг 10) по `decisions/0063` («каждая отмеченная читателем перечитанная фраза записывается в дефект понятности одной записью на прогон»), 2026-10-18. Пункт планки: Q3 (слова не должны вести к неверному выводу). Требования: REQ-050, REQ-051 (критерии 6 и 8), REQ-052, REQ-053; слова карточек — REQ-044, REQ-047; журнала — REQ-045, REQ-046, REQ-048.

## Что не так

Условие владельца для гайда — «максимально для рядового пользователя понятен» (`docs/owner-requests/2026-10-17-guide-and-english.md`). По правилу `0063` выпуск состоялся: все шаги читателей, кроме одного, пройдены (ответ верен по смыслу, без подсказки, не больше 3 шагов). Шаг читателя части 2 по вопросу «где нужно моё решение?» не пройден: читатель искал ответ в карточке агента 5 шагов, нашёл только фразу «Об ошибках и о том, что агент ждёт человека, Claude Code сейчас не сообщает» (`UNKNOWN_ERRORS`, `tools/src/pixel-office/public/texts.js`) и сделал вывод «на странице этого не видно… уверенности нет»; справку не открыл. Владелец 2026-10-18 решил: «Выпускать, фразу — следом» — это известное ограничение выпуска (`0063`).

**Первым исправляется (решение владельца, `0063`):**

0. Фраза карточки `UNKNOWN_ERRORS` должна вести к ответу: решения владельца оркестратор спрашивает в разговоре с Claude Code, а не на странице (как в справке, раздел «Как работать с командой агентов», пункт 4, где ответ нашёл читатель части 5).

**Остальные отмеченные фразы и замечания** (дословно по списку BA-ANALYST `step-08c-ba-analyst.json`, I9 — перечитанные фразы и замечания читателей второго круга и наблюдения UAT):

1. Справка «Журнал»: «откройте её строку» — какую строку и что значит «открыть» (нажать «подробнее»).
2. Два способа в разделах «Журнал» и «Задачи» с разными названиями кнопок («события этой задачи» / «события в журнале») — не ясно, что это одно и то же.
3. Номера: «номер sample-r», «номер запуска sample-a · номер разговора sample-1» — ничего не говорят (читатели 1, 2, 5).
4. «закончила работу, итог не записан» — какой итог и почему не записан.
5. «свободен — по журналу у этой роли нет задачи «в работе»; это вывод по событиям, а не событие» рядом с «получил задание и начал работу» при «нет свежих данных» — кажется противоречием.
6. «если событий нет дольше 60 минут, страница пишет «нет свежих данных»: работа могла идти, но подтверждений нет» — работает агент или нет (читатели 2, 5).
7. «Что агент делает внутри — читает файлы, запускает команды, вносит правки, — Claude Code не сообщает.»
8. «Об ошибках и о том, что агент ждёт человека, Claude Code сейчас не сообщает» — ведёт к выводу «нельзя узнать, нужен ли я», не говорит, где спрашивают решение (причина провала шага читателя части 2; это п. 0).
9. «О сообщениях между агентами Claude Code не сообщает: известны только передачи задания и окончания работы».
10. Тур, шаг 4: «о чём событие молчит».
11. «в работе ничего нет · без свежих данных: 8» — 8 чего.
12. «Журнал не подтверждает, что эти задачи и строки основной сессии идут. Это не конец работы и не ошибка.» — работают или нет.
13. «описание написал передавший задание».
14. «3 из 3» — не сразу понятно, что это число строк.
15. Чем «открыть историю запроса» отличается от «события этой задачи».
16. «Pixel Office этих вопросов не показывает» — читатель искал на странице кнопку «нужно решение».
17. UAT: «папка sai/» не объяснена в «Словаре».
18. UAT: «Ревью» объяснено только в описании роли.
19. UAT: группа «Аудит» — слова «находки», «записи об ошибках» без пояснения.

Других замечаний читателей второго круга о понятности в итоге приёмки нет (`docs/uat/REQ-050-051-052-053-RUN.md`, раздел «Читатели»); наблюдение читателя 1 о кнопке «агент» не о понятности, и повтор 2 его не воспроизвёл (20 из 20 с первого нажатия, `step-08c-ba-analyst-r1.json`).
