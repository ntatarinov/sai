# ISS-0010 — После сбоя диска чат проекта отвечает «повторите позже» до перезапуска сервера

Серьёзность: LOW (первоначально записан как принятый остаточный риск `decisions/0025` W9; RELEASE-VALIDATOR, `step-29`, F2: Q10 нарушен, принятие риска исключением из планки не является). Статус: closed, 2026-10-10. Найдено: TEST-DESIGNER прогона `PROD-20261010-01` (`handoffs/PROD-20261010-01/step-12-test-designer.json`, I1). Пункт планки: Q10.

## Что не так

Если при отправке сообщения в чат без движка случается сбой диска, ядро оставляет замок записи за процессом сервера до конца процесса. Следующие сообщения проекта получают 409 «повторите через несколько секунд»; повтор не поможет до перезапуска Sai Team, то есть текст говорит неправду.

## Как исправить

Отдельный текст для случая «замок не снимается» либо снятие замка ядром после сбоя (REQ-012 или отдельная работа, решение CODE-DESIGNER). Тест на правильное поведение — после решения.
