# ISS-0025 — Две параллельные задачи без зависимости с одним именем файла сталкиваются в общей папке work/

Серьёзность: MEDIUM. Статус: open. Найдено: TEST-DESIGNER прогона `ISS-0023-20261011-01` (`handoffs/ISS-0023-20261011-01/step-06-test-designer.json`, I1). Пункт планки: Q1. Требования: REQ-013.

## Что не так

Если две задачи идут одновременно (`parallel` больше 1), не зависят друг от друга и сохраняют файл с одним именем, они сталкиваются в общей `work/`: вторая падает с `TASK_FAILED` (`result_file`, «Файл результата не найден в рабочей папке или недопустим»), потому что ядро уже приняло и удалило файл первой. Воспроизведено в черновике `RF-09` на текущем коде и на копии «до» — поведение то же, исправление ISS-0023 его не меняет и не вызывает. Проект REQ-013 (О9) утверждал изоляцию параллельных проверок; проверки изолированы, работы с одним именем файла — нет. `RF-09` запускает движок с `parallel: 1`.

## Как исправить

WF-03 с шага 1: решение (уникальные подпапки запуска или уникальные имена) с записью в `decisions/`, затем код и тест на два параллельных запуска с одним именем.
