# ISS-0027 — Исполнители пишут в память проекта «файл создан и подтверждён», когда файла нет

Серьёзность: LOW. Статус: open. Найдено: ISSUE-FIXER прогона `ISS-0023-20261011-01` (`handoffs/ISS-0023-20261011-01/step-01-issue-fixer.json`, I7; журнал настоящего запуска, события 75, 102, 125, 150). Пункт планки: Q1, Q10. Требования: REQ-013.

## Что не так

Память проекта пишут сами исполнители из своего ответа (`WORK_ANSWER_SCHEMA.memory`). Невыполнимое утверждение («файл создан и подтверждён») попадает в память и в следующие запуски как факт, проверяющий на него ссылается. Это не причина ISS-0023 (без неё проверка тоже бы упала), но усиливает путаницу.

## Как исправить

WF-03 с шага 1 и, вероятно, решение: память не должна принимать утверждения о состоянии диска, либо запись о файле строит ядро по принятому, а не исполнитель.

## Доказательство

`handoffs/ISS-0023-20261011-01/step-01-issue-fixer.json` (I7).
