# ISS-0009 — Пустой список названий не виден в итоговой строке `npm run traces`

Серьёзность: LOW. Статус: open. Найдено: RELEASE-VALIDATOR прогона `PROD-20261009-01`
(`handoffs/PROD-20261009-01/step-21-release-validator.json`, критерий 2); заведён DOC-UPDATER по поручению ORCH 2026-10-09.
Пункт планки: Q10 (проверка не должна молча ничего не проверять), Q2.

## Что не так

Файл `tools/traces/forbidden-names.sha256` сейчас содержит только заголовок: названий в списке нет, и проверка названий на
файлах Sai фактически ничего не проверяет. Итоговая строка `npm run traces` («файлов проверено …, следов 0, пропущено …»)
этого не показывает: при пустом списке она выглядит так же, как при полном и чистом. Человек видит «следов 0» и считает,
что и названия проверены.

## Доказательство

step-21-release-validator.json, критерий 2: файл хешей — одна строка заголовка, `npm run traces` — код 0, «следов 0».

## Как исправить

Предложение: при пустом списке итоговая строка пишет «названия: список пуст» (при непустом — сколько названий в списке; сами
названия и их число по отдельности не раскрывают ничего сверх файла хешей). Правка в `tools/src/traces/`, тест на оба случая;
проект REQ-014 (п. 2 — вывод) обновить в той же работе (Q12). Код выхода не меняется.

## Маршрут

По `docs/workflows/WF-03-defect.md`; срочности нет. ORCH подтверждает маршрут при запуске.
