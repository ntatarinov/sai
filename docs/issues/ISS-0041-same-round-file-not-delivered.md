# ISS-0041 — Задача, называющая файл задачи того же круга плана, файла не получает

Серьёзность: LOW. Статус: open. Найдено: REQ-ANALYST и CODE-DESIGNER (прогон ISS-0031-20261011-01), 2026-10-12. Пункты планки: Q1. Требования: REQ-013 (критерий 15).

## Что не так

Правило критерия 15 касается только принятых файлов прежнего круга. Если в первом круге плана две независимые задачи идут параллельно и вторая называет файл первой в `text`, файл она не получит: принятого файла ещё нет, а ядро зависимость не достраивает. Критерий 15 явно вынес этот случай в «не входит».

## Доказательство

`handoffs/ISS-0031-20261011-01/step-02a-req-analyst-r1.json` (граница «не входит»), `handoffs/ISS-0031-20261011-01/step-03-code-designer.json`.

## Как исправить

Решить, нужна ли для такого случая достройка `depends_on` по имени, которое задача-источник обещает в `done_when` (файл ещё не принят); при необходимости новый критерий REQ-013 и проект.

## Маршрут

WF-03 с шага 1.
