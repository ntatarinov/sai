# ISS-0042 — Задача, созданная командой пользователя, достройки зависимости не получает

Серьёзность: LOW. Статус: open. Найдено: CODE-DESIGNER (прогон ISS-0031-20261011-01), 2026-10-12. Пункты планки: Q1. Требования: REQ-013.

## Что не так

Задача, созданная командой пользователя (`cli.js` -> `addTask`), не проходит `validatePlan`: зависимость от задачи — источника файла ставит сам пользователь, ядро её не достраивает. Если пользователь забыл `depends_on`, повторится ISS-0031 для такой задачи.

## Доказательство

`handoffs/ISS-0031-20261011-01/step-03-code-designer-r1.json`, п. 11.

## Как исправить

Решить: достраивать зависимость и в `addTask` или показывать пользователю предупреждение о названном, но не подключённом файле; тест на путь `addTask`.

## Маршрут

WF-03 с шага 1.
