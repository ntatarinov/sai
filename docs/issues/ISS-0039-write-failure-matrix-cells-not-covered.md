# ISS-0039 — не закрыты две ячейки матрицы «цель × вид сбоя» критерия 11

Серьёзность: LOW. Статус: open. Найдено: TEST-DESIGN-VALIDATOR (`handoffs/ISS-0002-20261011-01/step-07-test-design-validator.json`, F2). Пункты планки: Q5. Требования: REQ-002 (критерий 11).

## Что не так

В `tools/test/apply.write.test.js` не хватает двух ячеек матрицы «цель × вид сбоя» из файла дефекта ISS-0002:

1. Вид «цель — ссылка» проверен для `apply-report.json` (W10, W11) и STATE.md (W12), но не для `proposed-actions.json`.
2. Вид «не обычный файл» проверен для `proposed-actions.json` (сокет, W52) и `apply-report.json` (канал, W51), но не для STATE.md. Тест «STATE.md — папка» лежит в `tools/test/cli.test.js`, а не в трёх файлах, которые называет команда критерия 11.

Код един для всех целей (`inspect`), мутанты M6, M17 и соседние ловятся, поэтому риск мал.

## Доказательство

`handoffs/ISS-0002-20261011-01/step-07-test-design-validator.json`, F2: сопоставление таблицы тестов с матрицей файла дефекта, построчно.

## Как исправить

WF-03 с шага 1 или один проход TEST-FIXER: добавить строки W для `proposed-actions.json` как ссылки и для STATE.md как канала (и сокета); либо записать в §13.4 дизайна REQ-002, что матрица не обязательна по ячейкам, и добавить `cli.test.js` в перечень файлов критерия 11.
