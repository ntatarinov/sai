# ISS-0040 — reviewContext даёт проверяющему только файлы самой задачи, а не файлы её зависимостей

Серьёзность: MEDIUM. Статус: open. Найдено: ISSUE-FIXER (прогон ISS-0031-20261011-01), 2026-10-12. Пункты планки: Q1. Требования: REQ-013, REQ-010.

## Что не так

Проверяющий правки не видит исходник: `reviewContext` передаёт ему принятые файлы только самой проверяемой задачи, а файлы задач, от которых она зависит, — нет. Задача, которая правит файл чужой задачи, проверяется без этого файла и не может оценить, что изменено. Воспроизведено.

## Доказательство

`handoffs/ISS-0031-20261011-01/step-01-issue-fixer.json`, место 3 диагноза (воспроизведение на копии «до»).

## Как исправить

CODE-DESIGNER: передавать проверяющему и принятые файлы зависимостей задачи (только чтение, с пометкой источника); регрессионный тест на исполнителе, который читает подсказку проверки; решение в `decisions/` (Q12). Ограничение размера подсказки — см. ISS-0026.

## Маршрут

WF-03 с шага 1.
