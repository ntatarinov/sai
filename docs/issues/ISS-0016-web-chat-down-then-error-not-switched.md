# ISS-0016 — Чат остаётся на «Нет связи» после перехода к отказу с текстом

Серьёзность: LOW. Статус: open. Найдено: CODE-DESIGN-VALIDATOR прогона `PROD-20261010-01` (`handoffs/PROD-20261010-01/step-47-code-design-validator.json`, N-6). Пункт планки: Q10 (показанное состояние правдиво).

## Что не так

Если первый опрос чата при загруженном проекте дал «нет связи», а следующий — отказ с текстом, признак `chatDown` не сбрасывается. Показывается «Нет связи с сервером Sai», хотя связь есть и сервер отвечает отказом (должно быть «Чат недоступен»). Описание экранов (п. 8.1a) этот переход не называет.

## Как исправить

Сбрасывать `chatDown` при любом ответе чата; описание уточнить; тест WEB-P17 (нет связи → отказ с текстом → «Чат недоступен»). Заодно (N-4, N-5 того же шага): в ячейку «Чат» строки «Связь потеряна после загрузки» добавить отсылку к 8.1a и назвать отступ строки «и ещё N» (6 px) в п. 5.6 и 5.8.
