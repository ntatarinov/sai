# ISS-0058 — Правило маскирования M7 скрывает хосты из трёх частей в адресах источников

Серьёзность: LOW. Статус: open. Найдено: UAT-RUNNER (прогон `REAL-20261013-01`, шаг 8), подтверждено RELEASE-VALIDATOR (шаг 9, F3), заведено DOC-UPDATER, 2026-10-13. Пункты планки: Q3. Требования: REQ-009 (критерий 12), REQ-013.

## Что не так

Правило M7 в `tools/src/pixel-office/mask.js` (`maskThreeParts`) принимает за секрет любой отрезок из трёх частей через точки. Хост из трёх частей (например, `minds.wisconsin.edu`) выглядит так же, поэтому в тексте, который проходит маскирование, адрес превращается в `https://[скрыто]/…`. Хосты из двух частей (`education.ua`, `kontur.ru`) и из четырёх (`127.0.0.1`) правило не трогает.

Ошибка безопасная: секрет не просочится. Но читатель не может проверить источник. В файле результата Исследователя настоящего запуска два адреса стали `https://[скрыто]/blog/35618/` и `https://[скрыто]/items/0c997492-…`; ссылки, которыми исследование подкрепляет свои выводы, проверить нельзя.

## Доказательство

`docs/uat/REAL-RUN-20261013.md`, раздел «Что нашлось попутно», п. 1; `handoffs/REAL-20261013-01/step-09-release-validator.json` (`result.findings`, F3: метки `[скрыто]` в двух строках файла Исследователя). Воспроизведение без запуска Claude: `maskSecrets("https://minds.wisconsin.edu/items/abc")` из `tools/src/pixel-office/mask.js` даёт `https://[скрыто]/items/abc`; `maskSecrets("https://education.ua/blog/1")` и `maskSecrets("host 127.0.0.1 ok")` текст не меняют (проверено 2026-10-13 при заведении дефекта).

## Как исправить

Отдельная работа по WF-03 с диагноза ISSUE-FIXER. Развилка для проекта CODE-DESIGNER: не принимать за токен отрезок, который стоит сразу после `://` или целиком похож на имя хоста (буквы и точки, последняя часть — известный домен верхнего уровня), или маскировать по признакам токена (длина, смесь регистров и цифр), а не только по числу частей; выбор записать в `decisions/` (Q12). Охранные тесты `M7-jwt`, `M7-no-eyJ`, `M7-file` (`tools/test/pixel-office-helpers.js`) и проверка `127.0.0.1`/`panels.js` в `tools/test/pixel-office-hook.test.js` не ослаблять; добавить регрессионный тест: хост из трёх частей в адресе не скрывается, настоящий JWT скрывается.
