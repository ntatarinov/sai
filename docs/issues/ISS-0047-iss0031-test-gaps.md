# ISS-0047 — Пробелы тестов ISS-0031

Серьёзность: LOW. Статус: open. Найдено: TEST-DESIGN-VALIDATOR (прогон ISS-0031-20261011-01), 2026-10-12. Пункты планки: Q5. Требования: REQ-013 (критерий 15).

## Что не так

(1) EN-76 (`tools/test/team-engine-docs.test.js`) ищет вызовы по списку имён: локальный помощник с таким именем даёт ложное красное, помощник с другим именем, вызывающий неохраняемый запуск, не ловится. (2) Путь отказа «больше 40 зависимостей» проверен чистой функцией SF-06, на движке (PLAN_RETRY, затем ожидание) не проверен. (3) SF-07 закрепляет текст `ACCEPTED_RULE` дословно. (4) SF-02…SF-08 строят состояние литералом в форме редуктора: смена формы краснит тесты, не проверяя поведения.

## Доказательство

`handoffs/ISS-0031-20261011-01/step-07-test-design-validator.json` (F1, F3, F4).

## Как исправить

Один проход TEST-FIXER или WF-03: EN-76 проверять по импортам охраняемых помощников; движок-тест на `too_many_deps`; ключевые слова вместо дословного правила; общий помощник состояния.
