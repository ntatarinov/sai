# ISS-0012 — Отказ движка в чате теряет признак «откат не удался»

Серьёзность: LOW. Статус: open. Найдено: REVIEWER прогона `PROD-20261010-01` (`handoffs/PROD-20261010-01/step-35-reviewer.json`, N2). Пункт планки: Q10 (текст отказа должен быть правдив). Родственный случай: `ISS-0010`, место М6.

## Что не так

Сообщение в чат уходит через канал движка. Если у движка откат записи события CHAT не удался, функция `refuse()` в `tools/src/team/engine/engine.js` (около строк 924–926) передаёт наружу только код и текст, а признак отката теряется. Сервер тогда говорит «сообщение не сохранено», хотя строка могла сохраниться. Для пути без движка (прямая запись ядром) эту ситуацию различает `chatDiskUnsure`.

## Как исправить

Передавать признак отката из `refuse()` в ответ канала и в `chatFailure`; тест на оба исхода (откат удался / не удался) в тесте канала и в тесте сервера. Проект — CODE-DESIGNER (WF-03), правка затрагивает движок REQ-013 и канал (решение 0020).
