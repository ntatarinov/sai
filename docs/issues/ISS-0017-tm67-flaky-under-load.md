# ISS-0017 — TM-67 нестабилен при сильной нагрузке на машину

Серьёзность: LOW. Статус: open. Найдено: TEST-DESIGN-VALIDATOR прогона `PROD-20261010-01` (`handoffs/PROD-20261010-01/step-48-test-design-validator.json`, F2). Пункт планки: Q2 (тесты устойчивы и не зависят от часов и нагрузки).

## Что не так

Под нагрузкой в 8 фоновых циклов `yes` на 10 ядрах один полный `npm run check` дал 1108 из 1109: упал TM-67 в `tools/test/team-recovery.test.js` («round 17: RUN_FINISHED 0 !== 1»). Отдельно тот же файл под той же нагрузкой упал в 1 из 4 прогонов. Без нагрузки `npm run check` проходит стабильно (каждый раз 1109 из 1109). К правкам REQ-011 и `ISS-0010` не относится: проверено на коде без них.

## Как исправить

Разобрать, чего именно ждёт TM-67 (раунд 17: событие завершения запуска) и заменить ожидание по времени на ожидание события или добавить повтор опроса с пределом; тест при нагрузке 8 циклов `yes` проходит 20 раз подряд.
