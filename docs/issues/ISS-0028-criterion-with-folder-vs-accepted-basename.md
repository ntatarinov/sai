# ISS-0028 — Критерий «сохранён в out/memo.md» не совпадает с принятым именем без папки: поведение не определено

Серьёзность: LOW. Статус: open. Найдено: REVIEWER (`handoffs/ISS-0023-20261011-01/step-05-reviewer.json`, F3) и TEST-DESIGNER (`handoffs/ISS-0023-20261011-01/step-06-test-designer.json`, I2) прогона `ISS-0023-20261011-01`. Пункт планки: Q1. Требования: REQ-013 (критерий 14), решение `decisions/0035`.

## Что не так

Ядро хранит принятое имя без папок (`t-0001-1-memo.md`), список соответствия содержит только «memo.md → t-0001-1-memo.md». Критерий вида «сохранён в out/memo.md» с папкой не связан ни с одной строкой; проверяющий, строго следуя правилу `SAVED_AS_RULE`, отметит «не выполнено». Проект исправления ISS-0023 поведения для папки не определял. `RF-14` фиксирует только факт (карта без папки), а не желаемое.

## Как исправить

Нужно решение (владелец или CODE-DESIGNER с записью в `decisions/`): считать ли «out/memo.md» совпавшим с «memo.md» (правка `SAVED_AS_RULE`) или оставить как есть и сказать об этом в README. Затем WF-03.

`handoffs/ISS-0023-20261011-01/step-05-reviewer.json` (F3), `handoffs/ISS-0023-20261011-01/step-06-test-designer.json` (I2, `RF-14`).
