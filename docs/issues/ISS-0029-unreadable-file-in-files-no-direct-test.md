# ISS-0029 — Путь «принятый файл в files/ нечитаем» не имеет прямого теста

Серьёзность: LOW. Статус: open. Найдено: TEST-DESIGNER прогона `ISS-0023-20261011-01` (`handoffs/ISS-0023-20261011-01/step-06-test-designer.json`, итог и I5: «путь „файл в files/ нечитаем“ без теста»). Пункт планки: Q2 (тест на путь отказа). Требования: REQ-013.

## Что не так

Среди тестов `RF-01…RF-14` нет прямого теста на путь, когда принятый файл в `files/` прочитать нельзя (`step-06`: «путь „файл в files/ нечитаем“ без теста»). Что именно делает код в этом случае, этим тестом не зафиксировано.

## Как исправить

WF-03 с шага 6: тест на нечитаемый файл в `files/` (проверка, что задание строится и состояние не портится).

## Доказательство

`handoffs/ISS-0023-20261011-01/step-06-test-designer.json` (I5).
