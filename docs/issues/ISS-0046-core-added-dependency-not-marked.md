# ISS-0046 — У достроенной ядром зависимости нет отметки «добавлено ядром»

Серьёзность: LOW. Статус: open. Найдено: CODE-DESIGN-VALIDATOR (прогон ISS-0031-20261011-01), 2026-10-12. Пункты планки: Q14. Требования: REQ-013 (критерий 15), REQ-010.

## Что не так

Когда проверка плана достраивает `depends_on`, ни в журнале проекта, ни в проекции не остаётся отметки «добавлено ядром» (формат журнала по решению 0043 не менялся). При настоящем запуске нельзя понять, поставила ли зависимость модель сама или её достроило ядро, и потому нельзя оценить, как ведёт себя модель с новым блоком.

## Доказательство

`handoffs/ISS-0031-20261011-01/step-03b-code-design-validator-r1.json` (N3), `decisions/0043-iss0031-core-completes-file-dependency.md`.

## Как исправить

Добавить в событие плана список достроенных зависимостей (формат журнала меняется — решение в `decisions/`, REQ-013) и показывать его в проекции; тест. Сделать до настоящего запуска, иначе его итог труднее читать.

WF-03 с шага 1.
