- Задача `{kind:"task", key}`: доверенные и помеченные строки `SubagentStart`/`SubagentStop` с `agent_id = key`;
  строки `PostToolUse` с `agent_id = key` **или** `launched_agent_id = key`.
- Строка основной сессии `{kind:"main", key: main:i}`: строка `i` (`UserPromptSubmit`); `Stop`, который её закрыл
  (`end_index`); записи оркестратора, привязанные правилом 5 к запросу `req:i` (номер записи в
  `history.requests[].notes[].index`).
- Пометка «Задача» — `TASK_MARK` с `roleName` и 8 знаками ключа; у строки основной сессии — `TASK_MARK_MAIN`.

### 4.3 Переходы в раскрытии события

| Строка | Поле «Агент» | Поле «Задача» (задача события — по абзацу «Задача события» REQ-046) |
|---|---|---|
| SubagentStart, SubagentStop | «открыть агента» → карточка запуска `agent_id`; задачи нет — текст `AGENT_NOT_FOUND` | «к задаче в панели» (или `NOT_IN_PANEL`), «события этой задачи», «открыть историю запроса» (окно задачи; нет — `NO_WINDOW`); задачи нет — без кнопок |
| PostToolUse | «кто передал» → карточка передавшего (`agent_id` → запуск; нет `agent_id` → основная сессия, `mainRowOfEvent`) | первой «кому» → карточка запущенного (`launched_agent_id`); затем три перехода по задаче запущенного; задачи нет — текст `TASK_NOT_FOUND`, без кнопок |
| UserPromptSubmit, Stop | «открыть агента» → карточка основной сессии (`mainRowOfEvent`) | три перехода по строке основной сессии (окно — `windowOfMainRow`) |
| SessionStart, SessionEnd | «открыть агента» → карточка основной сессии на первой строке сессии | «к задаче не относится», без кнопок |
| запись оркестратора | кнопки нет | строка основной сессии её запроса (если привязана) — три перехода; иначе без кнопок |
| помеченная строка | как у её вида | «к задаче не относится», без кнопок (прежнее правило) |

«События этой задачи» ставит `task`, снимает остальные фильтры и поиск, `base = "all"`, `shown = JOURNAL_LIMIT`
(`decisions/0058`, дополнение 2, п. 4); раскрытие остаётся открытым и в фокусе, если строка входит в задачу, иначе
фокус — на пометке «Задача». «К задаче в панели» — `panelTarget = key`, перерисовка панели, прокрутка тела панели к
элементу (элемент целиком виден), фокус на элементе (`tabindex="-1"`).

### 4.4 Поиск

Строка подходит, если `searchText` содержит введённое (обрезанное по краям, в нижнем регистре); пустое — поиск не
действует. Поиск действует по каждому вводу (событие `input`).

### 4.5 Запуск по умолчанию (критерий 8 REQ-047)

Среди задач роли (порядок `model.list`): есть `in_progress` — первая из них; иначе задачи `stale` и `restarted` —
та, у кого самое позднее собственное событие; иначе — самое позднее собственное событие среди всех. Собственное
событие — `max(last_start_index, последний из stop_indices)` (доверенные строки модели). Строки `PostToolUse` и
записи в выбор не входят.

### 4.6 Строка основной сессии для запуска

`history.windowOfTask.get(key)` = `req:i` → `main:i`; окна нет → первая строка основной сессии сессии задачи (по
`start_index`); строк нет → `{row: null, session}`.

### 4.7 Основание строки «Задача» карточки основной сессии

`in_progress`, `stale`: «последнее событие сессии <дата-время> · <возраст> · `FRESH_LIMIT`» и второй линией слова начала
строки (случай 3, 4 или 5 `EVENT_TABLE`) · время. `completed`: «Основная сессия вернула ответ · <время Stop>».
`unrecorded`: закрывшее событие — следующий запрос (слова его случая) или SessionEnd (случай 2) и время: ищется первая
доверенная строка той же сессии после `start_index` вида `UserPromptSubmit` или `SessionEnd`. `restarted`:
`MAIN_CARD.server_started` с временем самой ранней записи запуска после `start_index` (как D11 прошлого проекта), без
возраста.

### 4.8 «кого запустила в этом запросе»

Задачи, у которых `launched_by.kind === "main"`, `session_id` = сессия строки и `history.windowOfTask.get(key)` =
`history.windowOfMainRow.get(row.key)`; у строки без окна — пусто (`CARD_EMPTY`).
