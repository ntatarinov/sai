## 0. Кратко

1. **Одно правило, одно место.** В `tools/src/picker/text-rules.js` появляется функция `forbiddenSign(text)` (одно регулярное выражение на весь перечень) и ничего больше в перечне
   не повторяется: `validate.js` вызывает её в проверке текста, `places.js` — в `tame()`. **Нового модуля нет**, поэтому закрытые перечни PK-6e, PK-7c, PE-8d и таблица `NODE_IMPORTS`
   не меняются (п. 2, D1; измерено на прототипе). Код реализации — около 30 строк в трёх файлах: `text-rules.js`, `validate.js`, `places.js`.
2. **Что запрещено** (п. 4): 60 знаков Cc (без U+0009–U+000D), все 170 знаков Cf, U+2028, U+2029 — **232 знака вне суррогатов**, и 2048 одиночных кодовых единиц U+D800–U+DFFF.
   Допустимо остальное: 1 111 832 знака (U+0009–U+000D, Zs, Co, Cn, Mn, U+FFFD, U+3164 …) и пары суррогатов. Перебор всех кодовых значений на прототипе дал ровно эти числа (Ф4).
3. **Порядок проверок текста** (п. 6): тип → запрещённый знак → длина → «ты» (только ru) → 18 слов; одна ошибка на место. Знак проверяется на **целом** тексте, а не на обрезанном
   (`trim()` снимает U+FEFF, U+2028, U+2029 по краям — Ф6, мутант М22).
4. **Две строки ошибки** (п. 6): «Недопустимый знак U+200B (невидимый или управляющий). Удалите его из текста.» и «Непарная половина знака U+D800. Удалите её из текста.»; код — первого
   запрещённого знака слева направо, `U+` и не меньше четырёх прописных шестнадцатеричных цифр; для знака вне BMP — код знака (U+E0001), для одиночной половины — кодовая единица.
5. **`show()`/`tame()` заменяют одиночный суррогат на «_»** (п. 7): в строках `check` и `serve` нет U+FFFD; для остальных 1 112 064 кодовых значений `tame()` даёт то же, что до правки (Ф7).
6. **Расхождение с критерием 1** (п. 17, О1; принято — `0076` п. 13): из 1 048 576 пар «старшая + младшая» **127 пар кодируют запрещённые знаки Cf вне BMP** (U+110BD, U+110CD, U+13430–U+1343F, U+1BCA0–U+1BCA3,
   U+1D173–U+1D17A, U+E0001, U+E0020–U+E007F). Они запрещены по перечню (б); допустимы 1 048 449 пар. Текст критерия «каждая пара допустима» неточен; проект и тест следуют перечню.
7. **Охранные тесты прежних требований** (п. 9): на прототипе правило сделало красным ровно один из 234 тестов `picker-*` — SF-6k (Ф3). Он заменяется тремя тестами (а, б, в);
   SU-8 получает шесть проверок. После таблицы замен `npm run check` проходит (1864 теста из 1864 на прототипе, было 1862).
8. **Образцы** `tools/test/fixtures/picker-text/` — 37 файлов поимённо (п. 8), вывод каждого измерен на прототипе. На метке 26 из 28 образцов с запрещённым знаком получают код 0 («в порядке») — это и есть дефект; ещё два дают другую ошибку (длина, 19 слов); два образца показа печатают EF BF BD; два ответа E_JSON прежние; пять принимаемых проходят.
9. **Мутанты**: 54 в п. 12.2; 42 применены к прототипу и убиты набором проб (Ф17).
10. **Подшаг один** (п. 10): правка трёх файлов и README; красных тестов между шагами 2 и 5 — один (SF-6k).
11. **Вопросы проекта О1–О8 решены ORCH**: `decisions/0076`, дополнение 3, пп. 12–15 (п. 17); по О6 и О8 новых ответов нет, действует написанное. Проект с записью не расходится.

## 4. Что запрещено и что допустимо

Знак текста для посетителя запрещён, если он: (а) Cc, кроме U+0009–U+000D, — 60 знаков (U+0000–U+0008, U+000E–U+001F, U+007F–U+009F, среди них U+0085); (б) Cf — 170 знаков:
U+00AD (1), U+0600–U+0605 (6), U+061C, U+06DD, U+070F (по 1), U+0890–U+0891 (2), U+08E2, U+180E (по 1), U+200B–U+200F (5), U+202A–U+202E (5), U+2060–U+2064 (5), U+2066–U+206F (10), U+FEFF (1),
U+FFF9–U+FFFB (3), U+110BD, U+110CD (по 1), U+13430–U+1343F (16), U+1BCA0–U+1BCA3 (4), U+1D173–U+1D17A (8), U+E0001 (1), U+E0020–U+E007F (96); (в) U+2028, U+2029; (г) одиночная половина пары (2048 единиц).
Всего 60 + 170 + 2 = 232 знака вне суррогатов. Список (б) записывается в тесте литералами с пометкой «Юникод 17.0»; расхождение с `\p{Cf}` движка — красный тест с перечнем разошедшихся знаков.

Допустимо всё остальное, в том числе: пробелы Zs (U+0020, U+00A0, U+202F, U+2000–U+200A, U+3000); пять знаков U+0009–U+000D (в файле — только записью `\t`, `\n`, `\u000B`, `\f`, `\r`; сырые знаки < U+0020 внутри строки отвергает
разбор — E_JSON, без изменений; сырые байты одиночного суррогата — E_JSON «не UTF-8», без изменений); буквы всех алфавитов, знаки с ударением (е + U+0308), цифры, символы (₸, №); эмодзи не склеенные U+200D (один знак, знак + U+FE0F, пара суррогатов, флаг из двух
региональных знаков); Co (U+E000), Cn (U+0378), Mn (U+0301), U+FFFD, и остаток невидимых знаков (U+3164 и др., О6).

## 5. Формы данных и функции по файлам

### 5.1. `text-rules.js` (меняется: добавляется)

* `FORBIDDEN` (не экспортируется) — выражение п. 2 D2.
* `forbiddenSign(text: string) → null | { unit: number, half: boolean }` — первый запрещённый знак слева направо; `unit` — код знака (для половины пары — кодовая единица, 0xD800–0xDFFF), `half` — истина для половины.
  Чистая функция: не меняет вход, не бросает на любой строке, не читает часы и среду; на строке без запрещённых знаков — `null`.

  «😀» → `null`; «а\tб\nв» → `null`; пустая строка → `null`; U+FEFF в начале → `{unit: 0xFEFF, half: false}`.
* Остальное (`trimmedLength`, `phrasesOf`, `wordCount`, `wordsOf`, `hasSecondPerson`, `wordsProblem`, `textProblem`) — без изменений; их тесты (`picker-parse.test.js`, строки 440–521) не затронуты (в их входах запрещённых знаков нет).

## 14. Абзац README (проект текста; BACKEND-DEV может уточнить слова, не снимая пяти слов и правил фраз)

> Тексты для посетителя не должны содержать невидимых и управляющих знаков. Команда `check` отвергает такой текст строкой с кодом `E_TEXT`: в ней место и код знака, например `U+200B`. Знак `U+200B` невидим и склеивает слова.
> Знак `U+202E` переворачивает текст после себя. Такие знаки обходят правило «фраза не длиннее 18 слов» и запрет слова «ты». Удалите знак из текста и проверьте файл снова. Непарную половину знака (одиночный суррогат) команда тоже отвергает.
> Обычные пробелы разрешены, в том числе неразрывные `U+00A0` и `U+202F`: они нужны для чисел вроде «50 000». Эмодзи разрешены: «😀» и «❤️». Эмодзи, склеенные невидимым знаком `U+200D`, команда отвергает.

Проверено (Ф18): prettier принимает; пять слов найдены в разделе; самая длинная фраза — 17 слов; обращение на «вы».
