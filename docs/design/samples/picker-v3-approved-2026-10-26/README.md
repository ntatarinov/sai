# Макет 3: офис, в котором собирается ваше решение

Открыть: двойной щелчок по `index.html` (сервер не нужен, внешних ресурсов нет).

Компания (арендатор) выбирается в адресе: `index.html?tenant=stock` (Складеон, учёт товарных остатков)
или `index.html?tenant=agency` (Лидвейв, маркетинговое агентство). Внизу страницы есть переключатель.
Дополнительно: `?lang=ru|kk|en`, `?theme=light|dark`, `?still=1` (без анимации).

## Маршруты (после `#`)

| Адрес | Что это |
|---|---|
| `#/` | первый экран: что это, одна большая кнопка, команда машет рукой |
| `#/ask/N` | вопрос N из 5: один тап по карточке, ответ сразу ведёт дальше; справа внизу живой чек |
| `#/ask/N/e` | правка ответа из итога (после ответа возвращает в итог) |
| `#/result` | итог: чек, печать / Excel (CSV) / PDF, одно поле для заявки, кнопка WhatsApp |
| `#/my/<номер>` | «Мой запрос»: тот же офис, четыре этапа, личная ссылка (`?stage=1..4` задаёт этап для показа) |
| `#/board` | оператор: полоса офиса со счётчиками и доска заявок по четырём этапам |

## Файлы
- `data.js` — тексты интерфейса на трёх языках и данные двух компаний (название, цвета, табличка на двери, команда, вопросы, предложения). Весь облик берётся отсюда.
- `office.js` — пиксельный офис (canvas) и слой подписей поверх него.
- `app.js` — экраны, расчёт чека, маршруты, печать, CSV.
- `styles.css` — стили. `shots/` — снимки экранов.

## Клавиатура
На вопросе: цифры 1–4 выбирают карточку, 0 — «Не знаю», Backspace или стрелка влево — назад, Shift+Enter — «Хватит, покажите результат». Всё остальное — Tab и Enter.

## Оговорки
- Казахский текст — черновик, нужна проверка носителем языка (об этом сказано в подвале).
- Данные заявок хранятся только в браузере (localStorage). Ссылка WhatsApp — демонстрационный номер.
- Расчёты в макете условные.
