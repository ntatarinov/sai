# Дизайн блока «Что работает сейчас» (read-only review, 2026-11-22)

Пути: S = app/public/css/site.css, T = app/public/shared/i18n/texts.js, H = how.html, D = js/pages/demo.js, L = docs/design/V1-public-look.md, E = app/test/e2e/landing.test.js.

## 0. Две поправки к logic-review (важно)
- Слово «срока» из предложенного текста («срока мы не называем») лежит в списке С запрещённых слов (app/scripts/word-lists.js:148-160). check-public (T-тексты, how.html) и shownTextFindings в E (browser.js:244) такой текст отклонят. Нельзя также: «дней/день», «минут», «цена», «бесплатно», «гарантия», «100 %». Пишем «Даты запуска пока нет».
- Третий чип «По приглашению» сегодня неправдив: ни приглашений, ни входа нет (M2 не начат). «Скоро» тоже намёк на близкий срок. Предлагаю два чипа: «Работает» и «Пока нет». «Приглашённые» остаются в тексте в будущем времени («смогут»). Если владелец хочет третий — только «Будет по приглашению», но не сейчас.

## 1. Компонент: один блок, одна разметка в двух местах
Это обычная info-панель (L 7.17, S:789 `.info`: `--card`, пиксельная рамка, padding 20/22, на телефоне 16/14, gap 6) с классом `now`. Внутри список в стиле L 7.14 (S:1407 `.rl li`, S:1415 `.rn`, `.rn b` 16/900, `.rn small` 14 `--ink2`).
```
section.info.now[aria-labelledby]
  h3 «Что работает сейчас»
  ul.rl > li ×3 : span.stat(.on | без) + span.rn(b + small)
  p (16, --ink, не .fine) закрывающая строка
```
Новые классы только два: `.stat` (метка) и `.r-side` (обёртка колонки в результате). Класс `.chip` НЕ брать: это кнопка (S:1373: min-height 48, hover, рамка), E:969 ищет `#demo .chips .chip`.

Метка `.stat` берёт готовый словарь «номер шага» (S:845-881): состояние «выбрано» = «Работает», обычное = «Пока нет». Без новых токенов, TC-3 не затронут.
- `.stat`: inline-flex, gap 6, `flex:none`, padding 3px 8px, 12/800 uppercase .06em (как `.lbl`, S:582), min-height 24 (это не контрол, 44/48 не нужны), текст всегда словом, цвет не единственный носитель смысла.
- `.stat.on`: фон `--btn`, текст `--onbtn` (5.02 / 5.84), inset 2px `--ink`.
- `.stat` (без on): прозрачный, текст `--ink2` на `--card` 6.71 / 6.31, inset 2px `--ink2`.
- Квадрат-иконка не нужна; если хочется: `i` 12×12 как `.pp i` (S:1010-1028), но на экране результата рядом пипсы «Точность», их легко спутать. Лучше без квадрата.
- Тёмная/светлая темы: только токены `--card --ink --ink2 --btn --onbtn`, как у соседей. Литералов нет.

Раскладка строки `.rl li` по ширине:
- ≥ 480: DOM порядок stat, rn; визуально stat справа (`order:2; align-self:flex-start; margin-top:2px`), `.rl li` уже `space-between, gap 16`.
- < 480 (360-380): `li{flex-direction:column; align-items:flex-start; gap:8px}`, stat над заголовком. Причина: при 360 содержимое панели 304 px (360 − 2×12 gut − 2×2 рамка − 2×14), метка ~88 px, на текст остаётся ~200, заголовок 16/900 уйдёт в 2 строки. Столбец даёт полные 304, обрезки нет (LD-1 проверяет scrollWidth > clientWidth, page-checks.js:127).
- DOM-порядок «метка, заголовок, пояснение» читается скринридером как «Работает. Демо-опрос…».
- Панель на how.html: `max-width: 640px` при ≥ 760 (прецедент S:1447-1451 для examples), иначе 1200 px на 3 коротких строки.

Если владелец согласен на поправку требований, лучше метка «Как описать идею» (совпадает с h3 назначения H:202); тогда правятся TX-4, L 7.15/13.1, REQ-111 (путь как у ISS-0126/0128).

**«Точность подбора 5 из 5».** Это число учтённых ответов (D:867 `receiptCount`: «Не знаю» = 0.5), а не качество.
