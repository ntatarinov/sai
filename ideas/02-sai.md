# Идея 2 — Sai: подбор размера для Instagram-магазинов одежды

Записано: 2026-09-25. Статус: выбрана, спрос не проверен.
Проект: этот каталог, `sai/` («сай» по-казахски — «подходящий»).
Выросла из идеи владельца про AR-примерку одежды (см. [05](05-drugie-idei.md)).

## Суть в одной фразе

Покупатель Instagram-магазина открывает ссылку, вводит рост, вес и обычный размер —
получает рекомендуемый размер, видит себя в вещи по фото и нажимает «Заказать в
WhatsApp».

## Почему это

- **Размер — главная причина возвратов одежды** (около половины всех возвратов).
  Доказано.
- **Подсказка по размеру уменьшает возвраты.** Доказано экспериментами.
- **Небольшие Instagram-магазины без сайта** остались без таких инструментов: крупные
  площадки (Wildberries, Lamoda, Google) сделали примерку только у себя.

## Что не доказано

Заплатят ли магазины. Это проверяется только на месте.

## Проверка спроса (без кода, 1–2 недели)

1. Написать 20 Instagram-магазинам одежды в Алматы: сколько раз в день спрашивают
   «какой размер взять?», сколько обменов и возвратов из-за размера в месяц.
2. Тем, у кого часто, предложить платный пилот на месяц (ориентир 10 000 ₸).
3. **Старт**, если 1–2 магазина готовы заплатить. **Стоп**, если никто.

## Что можно делать с Sai сейчас

1. **Подготовить проверку спроса** — текст сообщения магазинам, вопросы, таблица
   ответов. *Начать с этого.*
2. **Сделать демо для показа магазинам** — кликабельная страница на 3–4 вещи: рост,
   вес, обычный размер → рекомендация → «Заказать в WhatsApp». Одноразовое, только
   для показа. *Вместе с пунктом 1.*
3. **Запустить Pixel Office (REQ-001)** — не зависит от магазинов; нужно решение
   владельца начать раньше продукта и выбор технологии.
4. **Написать требования к продукту** — чтобы после «да» от магазинов сразу начать
   разработку.

## Что важно при разработке

- Планка качества — своя, ниже нельзя: [`docs/quality-bar.md`](../docs/quality-bar.md).
- Размер считать по росту, весу, обычному размеру и посадке, а не по фото; фото —
  только для картинки и только с согласием.
- Нужны замеры каждой вещи (обхват, длина) — без них подбор неточный.
- Kaspi пока не трогать: в его карточку ничего не встроить.
- Примерка через API стоит около 35–40 ₸ за картинку — нужен лимит на покупателя.
