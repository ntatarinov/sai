# Идея 3 — Живой мост: правда о том, что делает ИИ

Записано: 2026-09-25. Автор — владелец. Статус: хобби; техническая часть входит в Sai
как Pixel Office (REQ-001).

## Суть

Панель показывает, что ИИ сделал на самом деле: какие агенты запускались, сколько
работали, что ответили. Источник — хуки Claude Code (UserPromptSubmit, SubagentStart,
SubagentStop, Stop), помечено `SOURCE: REAL`. У владельца это уже работает (панель
«VS Code — живой мост»).

## Что владелец хочет дальше

- **Подсказывать, что поправить в запросе до отправки** — учить человека работать с ИИ
  на его собственных примерах.
- Для тех, кто **далёк от программирования** и хочет видеть, что происходит.
- **Не для слежки начальства** («не жандармерия»): человек смотрит на себя сам.
- **Проверка профиля:** человек видит, каким ИИ его представляет по запросам, и
  подтверждает или исправляет.

## Что сильное

- Владельцу это интересно, и он делает это по своей воле.
- Используется своя база: агенты, конвейеры, Pixel Office из osnova.
- Подсказки на реальных примерах полезны. Пример со скриншота: повторный запрос «Ты не
  всё выполнил…» — значит, с первого раза не вышло; ответ агента «Report delivered to
  the caller.» — ни о чём не говорит.

## Что на рынке (проверено 2026-09-25)

- **Картинка уже есть бесплатно:** Pixel Agents (расширение VS Code, тоже на хуках),
  claude-office, pixel-agents-standalone, приложение для iPhone.
- **Подсказки по запросам** есть для разработчиков: Braintrust (Loop), Prompt Coach в
  Microsoft Marketplace.
- **Разбор реальных сессий для непрограммистов** — готового не нашёл.

## Риски

1. Платформа (Claude Code) может встроить похожее сама; формат хуков может поменяться.
2. Непонятно, кто платит: за «контроль» платят руководители, а это слежка, которую
   владелец не хочет.
3. Аудитория узкая: хуки есть только в Claude Code, а не в обычном чате с ИИ.

## Решение

- Техническую часть делаем в Sai как **Pixel Office на хуках** (REQ-001) — это заодно
  первый подъём планки над osnova.
- На деньги не рассчитываем.
- Проверка интереса: дать 5–10 людям, работающим с Claude Code; через неделю посмотреть,
  открывают ли сами и просят ли что-то добавить.
