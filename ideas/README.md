## С чего всё началось

- Наработки владельца — это не готовый продукт, а «завод»: умение быстро строить
  работающие системы с ИИ-агентами.
- Чужой проект, на который равняется владелец, — не основа для продукта, а образец для
  **планки качества** Sai, ниже которой нельзя: [`docs/quality-bar.md`](../docs/quality-bar.md).
- Цель владельца: своё дело — дополнительный доход, свой продукт, интересная задача.
